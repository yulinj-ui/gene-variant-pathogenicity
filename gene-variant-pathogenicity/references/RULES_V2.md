# 第二版：已核实范围与禁用项

版本0.2.0-test；来源核查日期2026-09-26。阅读本文件后使用脚本；original与review/USER_REVIEW仅为档案和审阅资料。用户最新明确选择：SNV/Indel积分优先、2015组合正常列出，CNV独立。未安装、未临床审定。

## 核实的含义

`source_checked_test_only`表示所列原文位置与本包限定计算已比对，不代表完整指南、疾病适用性、实验室SOP或病例已经获批。所有病例仍需来源与适用性记录，正式classification始终为空。原档案pending状态不批量转reviewed。

## 可用的限定计算

| 能力 | 使用范围 | 必须保留的限制 |
|---|---|---|
| Tavtigian 2020积分分区 | 审核后的整数证据分；边界已核实 | 不是证据获取/赋值引擎；不自动处理小数框架、BA1或疾病例外 |
| ACMG 2015表5结构对照 | 按已输入、已审核的强度计算各组合命中 | 不还原2015默认强度，不自动纳入后续SVI组合修订；良性中等/极强无对应分支时显示不可用 |
| CNV独立积分分区 | Loss/Gain分开；显式已审核分值 | 不自动选择条目、HI/TS、基因数、4O分值，不施加SNV两证据门槛 |
| REVEL区间 | Pejaver 2022表2，错义且身份/校准选择已核查 | 只显示候选区间，不直接生成代码。极低分研究区间保留；强度上限须声明，不能擅自选最高 |
| de novo小计 | 普通病例小计+高异质性病例小计（后者封顶1） | 输出是遗传模式修正前强度；不自动确认亲缘/新发/适用性，不产生PS2/PM6 |
| 引文、注释、质控 | 核验率计算、单源身份与交叉核对分离 | 质控参数全关闭；外部接口模式未实时验证 |

本包积分测试边界：SNV P≥10、LP≥6且<10、VUS≥0且<6、LB<0且>−7、B≤−7（只接受整数）。CNV P≥0.99、LP≥0.90且<0.99、VUS>−0.90且<0.90、LB>−0.99且≤−0.90、B≤−0.99。使用Decimal，不能因二进制浮点误差跨界。见SOURCE_CHECKS中的原始表格定位。

2015对照显示“表5结构按本次强度运行”，并非“完整复现原2015全部规则”。例：PVS1+PM2_Supporting按原表5结构不命中LP，而积分为9；2020 PM2官方建议又明确该组合可为LP。必须解释这一版本差异，不能把原表结构对照误称为现行SVI否定LP。

## 已落实的文字与工程规则

- 查询失败、未查询、无覆盖与成功查询未检出分开；均不能自动生成PM2。未提供频率保持null。本地人群库暂不使用。
- “首次报道”改为截至某日、所列检索范围内未发现。
- VV完成参考/身份校验后允许单源后果复核，但仍保留单源标签；冲突暂停后果依赖证据，独立证据继续整理。
- 分类、基因—疾病关联、样本检出可信度分栏；未评估关联不自动等同否定。Limited等自动分类上限仍未启用。
- 不按低外显率统一降级；不由血样0/N推生殖腺风险；不由病例n/N推胎儿个体概率。
- 报告取舍只给建议及理由，不模拟签发；VUS亚档仅内部描述。保留原十模块、产前矩阵、家系/相位/第二打击、近邻检索、对标、批量及再评估工作流。
- 同代码家族重复、PS2/PM6双列、PM1+PP3超Strong、同机制PVS1+PP3均阻断候选输出，不偷偷删分或挑高分类。
- 核验率由实际记录生成；元数据和主张内容分别核验；模板不预填示例结论。

## 已核对但仍逐例判断

- PM1的热点/关键功能域是和/或路径，同时核查良性反证；数据库出现罕见变异不自动等于良性。
- 重复的未知插入位置不是一律0，但长度、阅读框、NMD、相关转录本和LoF机制需满足；不把整段重复/异位插入套入基因内规则。
- PS3/BS3的对照数只是完整实验评价的一部分；原文要求良性与致病对照、对照表现、重复等前提，不能把“≤10”写成无条件Supporting。
- PM3点表区分P与LP：反式已确定时P=1.0、LP=0.5；相位未知时P=0.5、LP=0.25；纯合0.5（上限1.0）、VUS反式0.25（上限0.5）、VUS未知0。档案original表的「P/LP反式=1.0」「P/LP相位未知=0.5」为合并写法，LP两行应分别为0.5与0.25。受累、足够稀有、避免循环分类及纯合/VUS类别上限均需核对。单亲检测在原规范给出的限定情形可支持反式；不能普遍等同未知或确认。本版不自动赋PM3。
- 框内插入的RNA/蛋白机制逐例处理；不保留永久禁用通则，也不自动赋PM4/PS3。
- CNV 1B −0.60保留为待适用性复核的条款，不自动终止；4O范围可调整，但固定频率换算及新的“≥1%自动−1”均未启用。

## 明确禁用

下列没有自动处理函数或默认激活配置；输入记录中的数值只能留作审阅：

1. 本地MCC、relatedness、IBS0、孟德尔错误率、DP/GQ/VAF及LOD通过/拒绝阈值；从深度推平台LOD。
2. CNV全基因家族合并、4O固定映射/自动−1、内部HI标为官方HI3、外显率<10%自动降级。
3. PP1/PP4按基因比例乘分、2024小数积分及临时向下取整；尚未完成完整框架验证。
4. 自动再发风险、邻近病例推个人预后、自动产前报/不报。
5. BA1自动最终裁决、未核实VCEP、mtDNA/重复扩展/平衡重排专项自动分类。
