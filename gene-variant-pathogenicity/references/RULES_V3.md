# 第三版执行范围

版本 0.3.0-test，2026-09-27。以本文件和 RULE_STATUS_V3 为当前增量，第二版记录保留历史。积分优先、2015组合正常列出、CNV独立；正式classification保持null。

## 新增可用功能

1. PVS1 与 PM4 任意强度共同存在时阻断评分候选，不偷偷删分。原文见 [PVS1研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6185798/) 的 PVS1 Strength Levels。
2. review_helpers.py 的 PM3 计算器支持 SVI 2019 v1.0 病例权重及纯合/VUS类别上限。小计2对应Strong，再对应贝叶斯权重4；两种分数不能混淆。相位与频率等前提必须先审核，不自动从单亲检测文字推断反式。同一家系多记录需先人工整理，本工具拒绝重复family_id。重复家系采用不同别名仍需人工识别。
3. PS3/BS3 仅提供 Brnich Table 3 的已校准OddsPath查表。严格保留 > 和 <，恰等于阈值时落入较弱的满足区间。输入须有实验机制、验证、独立对照、重复、校准及VCEP审核记录。对照数量、物种和实验室名称不触发赋分。
4. PP1/PP4 只提供 Biesecker Table 4 查表：输入为已审核、已分配、已封顶的0–5分，最多一位小数。不自行舍入或截断；输出最大代码组合选项，不选择代码。完整家系统计、后验概率分配、原始诊断率换分继续禁用。
5. 报告可单列上述辅助计算，由输入重算，永不自动加到主总分。SNV辅助计算不接受挂在CNV报告中。

## 必须保留的原文限制

- PVS1机制Table 1的降级条件为至少Moderate，既往LoF证据要求跨外显子，单外显子有例外。正好10%的文本/表格边界保留复核；相关转录本、外显子LoF耐受情况不能省略。完整PVS1自动树仍禁用。
- 基因—疾病关联按具体疾病和遗传方式记录，未查询到不改写成否定。Bean对Moderate关联的措辞不是无例外硬上限，不自动套用固定上限。
- PS3/BS3通常需实验对照、重复及变异验证；原文有既往已充分验证实验的有限Supporting路径。该例外需原始性能资料，不能用“经典实验”标签自动放行。
- PP1/PP4未患病者计分需外显率条件，定相亲代不重复计数；“27个基因座”不是通用阈值。AR复合杂合不共分离不能给双方各−4。Table 4两代码来自同一联合证据，不代表两条独立证据，不用于满足ACGS最少两条要求。
- BA1核对的是该位点观察等位基因数，而非数据库总人数。历史九例不是完整现行名单，也不是当前分类库。

## 框架和禁用项

维持Tavtigian2020整数分区：P≥10、LP6–9、VUS0–5、LB−1至−6、B≤−7。points_profile省略或为Tavtigian_2020可运行；其他值报错。该参数仅描述SNV配置，CNV仍独立。ACGS门槛和特定例外不混入；未推出新正式分类策略。

BA1、PP5/BP6、完整PP1/PP4算法、本地频率/诊断率/质控阈值、自动风险、CNV条目和4O映射、未经核实VCEP及专项规则仍禁用。服务缺失保留unavailable、未查询、失败、冲突等状态，不用零代替。人工已审核证据仍可按DATA_CONTRACT输入；程序只做结构、去重与算术检查，不能证明医学审阅有效。
