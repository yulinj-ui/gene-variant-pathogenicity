## 第一批：事实与输出一致性

### R01｜没有查到人群频率，能否赋 PM2

**结论**：同意修订。"查询失败"与"查询成功、确认稀有"必须分开，前者一律记为"未评估"，不赋 PM2。

**依据**：ClinGen SVI 的 PM2 建议（2020）把 PM2 降为 Supporting，并要求核对该位点在人群库中的覆盖是否充分。数据缺失本身不构成证据。

**人群库建议**：
- 以 gnomAD v4.1 为主，核对 exome/genome 覆盖和过滤状态；东亚人群补查 ChinaMAP 和 CMDB（中国百万人群库）。
- AD 病要求缺失或极低频；AR 病允许低频携带，阈值按疾病的最大可信等位基因频率或 VCEP 规定。
- 内部库只有在已知总样本数和表型构成时才能计入；否则只能写”内部库未见"，不参与赋值。目前本地库入组病例尚少，暂不考虑本地库的相关频率查询


### R02｜数据库没有记录，能否写"首次报道"

**结论**：同意。统一表述为："截至检索日期，在所列数据库与文献范围内未发现既往记录。"

**依据**：属逻辑问题，检索范围之外无法证明没有报道。改用该表述不影响现有的扩大检索功能。

### R03｜蛋白改变验证什么时候通过

**结论**：同意采用五种状态（双源一致／单源已注释／冲突／未知／不适用）。**建议允许单源路径**，前提是该来源本身经过参考序列校验，并在报告中标出"单源"。

**依据**：HGVS 身份核验（参考序列是否匹配）与后果注释是两件事。
- HGVS 身份核验：建议用 VariantValidator（或 Mutalyzer）。
- 后果注释：用 Ensembl VEP（或现有流程中的 ANNOVAR）。
- VariantValidator 通过、VEP 单源注释的结果可以直接使用。
- 两源冲突时，暂停依赖后果的证据（PVS1、PM4、PP3 等），其余证据继续收集。
- AI 推导的结果不算作一个来源。

### R18｜报告模板的医学质控

**结论**：全部同意，不需要医学偏好来决定。

**依据**：
- **核验率**：按"实际已核验数 ÷ 需核验数"计算，分母为 0 时显示"不适用"，不得预填 100%。建议在报告中显示该比例。
- **重复计分**：剪接变异已用 PVS1 时，不能再对同一剪接预测加 PP3（Walker 2023）。PVS1 与 PM2_Supporting 可以共存。
- **REVEL 分档**：统一按 Pejaver 2022：
  - PP3：Supporting ≥0.644，Moderate ≥0.773，Strong ≥0.932
  - BP4：Supporting ≤0.290，Moderate ≤0.183，Strong ≤0.016
  - 若技能有意更保守，必须写明原因。

### R20｜上传的文件能否自动成为最高优先级规范

**结论**：同意"先登记版本再使用"。
- **基线**：各规范的现行正式版（清单见 R16）。
- **课件**：定位为"解释层"，帮助理解，不直接启用为规则。
- **课件中超出规范的内容**：登记为"待验证扩展"。
- **历史版本复现**：允许，但报告中写明所用版本。

## 第二批：证据框架

### R04｜基因未被数据库评估，是否只能判 VUS

**结论**：接受报告固定分三栏：**变异分类**、**基因—疾病关联**、**样本检出可信度**。

**依据**：ClinGen 基因—疾病有效性框架分为 Definitive、Strong、Moderate、Limited、Disputed、Refuted，另有"未评估"。
- **Limited**：该疾病下的致病结论上限为 VUS。
- **Disputed / Refuted**：不做 P/LP，但不影响判良性。
- **未评估**：不是否定。应回到原始文献，按 ClinGen 方法自行评估关联强度，不自动套用上限。
- 检测质量问题属于"本样本检出待验证"，不改写该等位基因本身的分类。

### R05｜"至少两条证据"与单项足以成立的情形

**结论**：
- **SNV/Indel**：主判用 Tavtigian 2020 积分体系；ACMG 2015 组合规则作为对照，两者不一致时并列输出，不挑较高类别。
- **CNV**：单独使用 Riggs 2020 积分，不继承"至少两条"的门槛。

**依据**：
- ClinGen SVI 支持积分体系。它能解决 2015 组合规则的已知矛盾：例如 PVS1 + PM2_Supporting 按 2015 组合是 VUS，按积分为 8+1=9，属 LP。
- 积分阈值：P ≥10，LP 6–9，VUS 0–5，LB −1 至 −6，B ≤−7。
- 单项即可成立的情形只有两种：BA1；CNV 中完整覆盖已确立 HI 基因（2A，1.0 分）。无需新造"PVS1_Stand-alone"之类的代码。

**补充**：实验室目前正式签发用的是 2015 组合为主，同时参考积分。可先保留2015组合为主判、积分作为核查，并在报告中写明。

### R06｜重复没有断点证据，必须 0 分吗

**结论**：不必一律 0 分。按 SVI PVS1 决策树（Abou Tayoun 2018）：

| 情形 | 强度 | CNV 对应（Riggs Gain 2I） |
|---|---|---|
| 已证实串联 + 移码 + 预测 NMD | PVS1 | 0.90 |
| 推定串联 + 移码 + 预测 NMD | PVS1_Strong | 0.45 |
| 已证实非串联，或阅读框/NMD 无法确定 | 不赋值 | 0 |

**依据**：Abou Tayoun 2018 决策树原文即如此划分。原技能"推定串联 0.45"本身没错，缺的是"必须满足移码和 NMD"这一前提；另一处"方向不明默认 0"只适用于前提不满足的情况。

**默认框架**：SVI 通用规则；该基因有 VCEP 时以 VCEP 为准。

### R07｜外显率低于 10%，能否自动降为 VUS/B

**结论**：删除该自动阈值。分类照常按 Riggs 评分，外显率单列一栏。

**依据**：Riggs 2020 明确允许外显率降低的复发 CNV 判为致病（如 16p11.2、15q13.3 等神经发育易感区域），且分类与个体临床意义分开。"<10% 自动降级"在规范中找不到出处。

**报告呈现建议（属本地政策）**：已知神经发育易感 CNV 写入产前主报告，单设"易感性/外显不全 CNV"小标题，写明外显率区间及来源，并配合遗传咨询。不能为了"不报"而改分类。

### R08｜功能实验需要多少对照，动物实验是否天然更强

**结论**：
- **有 OddsPath 校准**：按 OddsPath 数值赋强度。
- **无校准**：对照变异（P + B 合计）≥11 个，最高 Moderate；≤10 个，最高 Supporting。
- **按物种固定上限的规则**：删除。

**依据**：Brnich 2019 的 PS3/BS3 建议，其中"11 个对照"明确是"缺乏严格统计分析时"的替代路径。
- 动物模型先要回答两个问题：是否检测了本变异本身？是否反映该病机制？
- 敲除模型只支持基因层面的关联，不能作为某个特定错义变异的 PS3。
- RNA 剪接实验与蛋白功能实验分开记录（按 Walker 2023）。

**补充**：相关基因是否有 VCEP 实验清单。没有则按通用规则执行。

### R09｜PM1 是否必须同时满足三个条件

**结论**：原技能写法有误。ACMG 2015 原文结构为"热点**和/或**关键且已确立的功能域，**且**无良性变异"，即"热点或功能域"二选一，再加上"区域内无良性变异"。必要资料未查完时记为"未评估"，不得以"降为 Supporting"的方式加分。

**依据**：
- ACMG/AMP 2015 的 PM1 定义。
- Pejaver 2022 建议 **PM1 与 PP3 合计不超过 Strong（4 分）**。这就是原稿所说"来源明确的独立性规则"，建议直接写入。
- "区域内良性变异"指已分类为 B/LB 或达到 BS1/BA1 频率的变异，不是 gnomAD 中出现过的任意罕见错义变异。

我实验室希望按照现有通用规则执行。

### R10｜de novo、亲缘、相位

- **R10a 积分区间空档**：改为连续区间：

  | de novo 病例分合计 | 强度 |
  |---|---|
  | < 0.5 | 不赋值 |
  | [0.5, 1) | Supporting |
  | [1, 2) | Moderate |
  | [2, 4) | Strong |
  | ≥ 4 | Very Strong |

  这是 SVI de novo v1.1 的数学含义，不需要偏好判断。

- **R10b 累计上限**："表型一致但非特异、遗传异质性高"一档合计最多 1 分，必须补上。

- **R10c 亲缘核验**：同意"做过 trio"与"确认了亲缘"分开记录。"已确认 de novo"的操作标准见**附录 A**。每例只算一次；已核验与未核验病例合在一条代码中计分，按 SVI v1.1 使用 PS2 或 PM6 加强度后缀，不双列代码重复加分。

- **R10d 相位**：按 SVI PM3 v1.0：
  - 与 P/LP 证实为反式：1.0 分
  - 与 P/LP 相位未知：0.5 分
  - 纯合：0.5 分，纯合合计最多 1.0 分

  文献写"复合杂合"时，要确认作者是否有双亲验证或读段/长读长定相，否则按相位未知计。

**补充**：本地亲缘核验工具与阈值、父母位点最低深度（默认建议见附录 A、B）。

### R11｜PP1/PP4 能否"积分乘以基因占比"

**结论**：删除乘法规则。长期目标是整套采用 ClinGen 2024 的 PP1/BS4/PP4 指导（Biesecker 等）。

**过渡方案**（核算器支持小数积分之前）：
- PP4 最多 Supporting，仅限表型高度特异、指向单一基因的情形。
- PP1 按 2024 表格查得强度后，**向下**取到最近的整档，并注明"保守取整"。向下取整是可以说明理由的保守规则，不同于随意四舍五入。
- 复杂家系、低外显率家系转人工统计评估。

**依据**：2024 指导把诊断率、共分离和基因座异质性放在同一似然框架中，"先乘概率再换算"在数学上与之不等价。从不同体系中挑选更有利的减数分裂门槛，不符合"整套采用"的原则。

### R16｜指南、课件、个人推论如何共存

**结论**：同意分层标记。建议基线清单：

1. ACMG/AMP 2015 + Tavtigian 2020 积分
2. ClinGen SVI 系列：PVS1（2018）、PM2（2020）、PS3/BS3（2019）、de novo v1.1、PM3 v1.0、PP3/BP4（Pejaver 2022）、剪接（Walker 2023）、PP1/PP4（2024）
3. CNV：Riggs 2020
4. 基因专用规则：ClinGen CSpec 登记库中该基因 VCEP 的现行版，**VCEP 优先于通用规则**

课件、讲者经验归入"解释层"；作者推论和草案不进入自动分类；冲突时并列记录，未解决的冲突不进入自动分类。

**补充**：已有的中文专家共识（如产前外显子组、CNV-seq 相关共识）纳入"本地 SOP 层"。

### R17｜CNV 规则四处

- **R17a（1B = −0.60）**：保留分值，删除"可终止评分"。Riggs 判级阈值：P ≥0.99，LP 0.90–0.98，VUS −0.89 至 0.89，LB −0.90 至 −0.98，B ≤−0.99。−0.60 单独只落在 VUS 区间，且仍须检查调控元件等其他条目。
- **R17b（同一家族基因按一个计）**：**先关闭**，保留逐基因计数。审阅者不记得 Riggs 正文有此普遍规则；找到原文出处前不应启用。
- **R17c（4O 扣分）**：保留 0 至 −1 的可调区间，**关闭**"1%→−0.90""2/12364→−0.15"等固定映射（规范中无此数值）。默认只在两个条件同时满足时自动赋 −1：①在规模足够、人群可比的数据库中频率 ≥1%；②CNV 类型相同、所含基因基本一致。其他情形人工给分并写明理由。
- **R17d（内部 HI 自评分 ≥10）**：内部评分只能标为"本实验室剂量评估"，不得写成 ClinGen HI=3；同一病例不得在 HI 论证和 CNV 第 4 部分病例评分中重复计入。


### R19｜RNA 显示框内插入，是否一律不能用致病证据

**结论**：删除"永久禁用 PVS1(RNA) 和 PS3"的通用禁令。
- **PVS1(RNA)**：框内插入不走"缺失关键区域／>10% 蛋白"路径，通常不适用。这一半原技能是对的。
- **PM4**：框内插入且不在重复区时，可以考虑 PM4（ACMG 2015 本就覆盖此情形）。
- **PS3**：若有独立的蛋白功能实验证明功能受损，可以使用，但不能与 PM4 基于同一观察重复加分。

**依据**：Walker 2023 讨论的是"需要蛋白层面证据"，并未禁止功能证据。

## 第三批：实验室与报告政策

### R12｜MCC、VAF、检出限能否统一设阈值

**结论**：拿到验证文件之前，关闭所有自动通过／拒绝规则，只保留数值字段和提示。VAF 偏离预期时一律输出"等位基因比例异常，原因待查"，不自动判为嵌合。

**依据**：AMP 的 MCC 指南要求阈值来自本实验室方法验证。VAF 受深度、比对偏倚、拷贝数影响；单个位点 VAF 不能估计 MCC。"NGS 约 1%、Sanger 10–15%"只是经验量级，不能当作本平台的检出限。

**补充**（目前以下本实验室还无法提供，稍后可以提供文献研究报告的支持）：
- 检测平台和分析流程版本
- 样本类型（羊水、绒毛等）
- MCC 检测方法（如 STR）及验证过的检出限
- 嵌合检出限验证数据
- 最低有效深度
- 复检 SOP

### R13｜父母外周血阴性，能否计算生殖腺嵌合上限

**结论**：保留"遗传咨询说明"模块，移除自动数值。
- 明确"外周血阴性不排除生殖腺嵌合"（深度与检出能力的关系见附录 B.2）。
- 区分"变异传递概率"与"子代患病概率"。
- AR 的 25% 必须以双亲都携带为前提。
- 如要写数值，只能引用有来源的经验值并注明适用条件，例如 Bernkopf 等 2023（Nat Commun）的个体化再发风险研究，以及文献常引用的"表观 de novo 群体再发风险约 1%–2%"量级。

**补充**：数值审核人由临床遗传医生或遗传咨询师签字确认。

### R14｜邻近变异病例比例，能否当作胎儿预后概率

**结论**：同意。原高／中／低三档改为"已有报道／明确阴性／未评估"，每项写明 n/N、年龄、来源；个体风险另设一栏，无依据时留空。

**依据**：个案文献存在确认偏倚，未记录某表型不等于没有该表型。这是统计解释问题，不涉及某个疾病的预后标准。

### R15｜产前 VUS 是否报告，VUS-High 能否近似 LP

**结论**：
- 分类、报告位置、临床行动三件事分开决定。
- VUS 亚档只作为内部描述，不能写成近似 LP。
- 技能只生成"建议报告位置 + 理由"，不模拟签发决定。

**依据**：ISPD 2022 关于产前外显子组的立场声明对 VUS 采取有条件报告：基因与胎儿表型高度相符，且可通过父母验证等方式进一步澄清。原稿提到的 2026 新建议无法核实（见"使用前须知"）。成人起病疾病、携带者状态、次要发现按知情同意范围处理。

## 附录 A｜本地亲缘／样本身份核验：常用工具与判定阈值

> 以下为业内常见做法和参考量级，可先启用，本实验室已知家系样本验证后再提供修改意见。

### A.1 基于测序数据的方法（WES/WGS 实验室最常用）

| 工具 | 原理 | 亲子关系预期值 | 常见判定用法 |
|---|---|---|---|
| **somalier**（目前最常用） | 从 BAM/CRAM/VCF 抽取约 1.7 万个高信息量常见 SNP 位点，速度快，WES/WGS 均适用 | relatedness ≈ **0.5**；**IBS0 ≈ 0** | 亲子：relatedness 0.4–0.6 且 IBS0 接近 0；无关个体 <0.1 左右；>0.9 提示同一样本或同卵双胎 |
| **KING** | 亲缘系数（kinship） | kinship ≈ **0.25** | 原文分档：>0.354 重复样本/同卵双胎；0.177–0.354 一级亲属；0.088–0.177 二级；0.044–0.088 三级 |
| **peddy** | 与 PED 文件自动比对，同时查性别、祖源 | 同 somalier | 直接标出"PED 记录与数据不符"，已逐渐被 somalier 取代 |
| **PLINK --genome** | IBD 估计 | PI_HAT ≈ 0.5，Z1 ≈ 1 | 传统方法，需先做 LD 剪枝，外显子数据上噪声较大 |

**关键细节：一级亲属有两种，必须分开。** 亲子与同胞的 relatedness 都约为 0.5，区分靠 **IBS0**：亲子在每个位点至少共享一个等位基因，IBS0 ≈ 0；同胞则有相当比例位点 IBS0 > 0。只看 relatedness，"父亲"样本被同胞样本替换时是查不出来的。

### A.2 配套核查（建议一并执行）

- **孟德尔错误率**：用 bcftools +mendelian 或 GATK 统计高质量位点。真实 trio 通常 **<1%**（高质量位点上常见约 0.1%–0.5%）；非生物学父母时会高出一个数量级。
- **候选 de novo 数量**：真实编码区 de novo 平均每个外显子组约 1–2 个。过滤后候选数明显偏多（如十几个以上），提示样本混淆、污染或流程问题。
- **性别核对**：X 染色体杂合率、Y 染色体覆盖度与登记性别一致。
- **胎儿样本须另做 MCC 检测**：亲缘分析显示"胎儿与母亲关系过近"或胎儿杂合率异常，都可能是母体细胞污染。MCC 须单独用 STR 等方法检测，不能用亲缘分析代替（呼应 R12）。

### A.3 基于 STR 的方法（部分国内产前实验室使用）

常用法医 STR 试剂盒（20 个以上位点），可与 MCC 检测共用一套实验。亲权判定通常参照司法鉴定亲权鉴定技术规范：**CPI ≥ 10000 为支持**，**CPI ≤ 0.0001 为排除**。该标准的具体条款和版本审阅者不能完全确定，请以现行规范原文为准。

## 附录 B｜父母位点"未检出"的最低深度要求

### B.1 常见过滤条件（以 slivar 等工具的 de novo 示例为代表量级）

| 项目 | 常用要求 |
|---|---|
| 父母该位点深度（DP） | **≥10–20×**（较严格的流程取 20×） |
| 父母基因型质量（GQ） | ≥20 |
| 父母变异读段 | **0 条**（部分流程允许变异读段占比 ≤2%–5%，但需人工复核） |
| 先证者 | DP ≥10–20×，GQ ≥20，VAF 0.2–0.8，FILTER=PASS |
| 位点性质 | 排除低可比对区、片段重复区、同源假基因区和已知系统性假阳性位点 |
| 人工确认 | IGV 查看三人读段；报告前通常用 Sanger 对三人验证 |

### B.2 这个深度能说明什么、不能说明什么

**能排除父母杂合**：若父母之一真实为杂合（变异读段应占约 50%），测到 N 条读段却 0 条支持变异的概率约为 0.5^N。10× 时约 0.1%，所以 **10–20× 足以排除"父母为普通杂合携带者"**。

**不能排除低比例嵌合**：若父母血液中嵌合比例为 10%，0 条变异读段的概率约为 0.9^N：

| 深度 | 漏检 10% 嵌合的概率 |
|---|---|
| 20× | 约 12% |
| 30× | 约 4% |
| 50× | 约 0.5% |

Sanger 检出限约 15%–20%，同样排除不了低比例嵌合。因此报告中应写"**未检出杂合变异（深度 X×，本位点嵌合检出能力约 Y%）**"，不写"父母无此变异"。这一点与 R13（生殖腺嵌合）直接相关。

## 附录 C｜与 SVI de novo v1.1 的对应：何为"已确认 de novo"

SVI 把 de novo 分为"已确认"与"推定"两类，影响计分（以表型高度特异为例，已确认 2 分，推定 1 分）。建议"已确认 de novo"须同时满足：

1. **父母身份已确认**：双亲均完成核验，亲子 relatedness 与 IBS0 符合预期；若用 STR，CPI 达到支持标准。
2. **父母位点检测充分**：深度与 GQ 达到本地阈值，变异读段为 0，IGV 已复核（或 Sanger 验证父母阴性）。
3. **先证者变异真实**：质量过滤通过；有条件时用 Sanger 或第二种方法验证。

**文献病例**：原文写明做过亲缘确认（如"paternity and maternity confirmed"，或给出核验方法）才按"已确认"计分；只写"de novo"或"parents negative"的，按"推定"计分。
