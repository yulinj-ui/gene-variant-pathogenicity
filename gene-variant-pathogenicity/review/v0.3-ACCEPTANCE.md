## 新增行为覆盖

| 范围 | 检查 |
|---|---|
| 防重复 | PVS1所有四种强度与PM4，两种顺序；独立PM4仍可计算 |
| 框架 | 非Tavtigian配置不静默接受；−6/−7边界；helper_results不能直接导入 |
| PM3 | trans/unknown的P、LP、VUS；0.5/1/2/4强度边界；纯合/VUS上限；重复病例/家系；缺来源和前提；字符串true不视为布尔审核 |
| PP1/PP4 | Table4全部六档；不自动选择代码；不自动舍入或封顶；未审概率分配时阻断 |
| 功能实验 | OddsPath严格阈值及等值；无校准、无验证不输出；对照数量/物种不替代校准；非有限值拒绝 |
| 报告 | 辅助结果重新计算、单列且不改变总分；保留十模块；未知辅助类型拒绝 |
| 原有功能 | 76项回归覆盖注释身份/冲突、CNV几何和分区、2015组合、去重、降级、引文与本地QC禁用 |

## 复现

解压后，在gene-variant-pathogenicity目录执行：

```bash
python3 scripts/run_offline_tests.py
python3 scripts/validate_package.py
python3 scripts/review_helpers.py pm3 tests/fixtures/helper-pm3-v3.json
python3 scripts/review_helpers.py pp1pp4 tests/fixtures/helper-pp1pp4-v3.json
python3 scripts/review_helpers.py functional tests/fixtures/helper-functional-v3.json
python3 scripts/render_report.py tests/fixtures/case-v3.json --output /tmp/variant-v3.md
```
