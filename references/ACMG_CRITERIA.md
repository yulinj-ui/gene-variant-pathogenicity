## 0. 证据强度与 Bayesian 积分对照（高勇报告，2026-09 正式版复核）

| 强度等级 | 致病侧积分 | 良性侧积分 | OddsPath（单条） |
|---------|-----------|-----------|-----------------|
| Very Strong (PVS) | +8 | -8 | 350 |
| Strong (PS) | +4 | -4 | 18.7 |
| Moderate (PM) | +2 | -2 | 4.33 |
| Supporting (PP) | +1 | -1 | 2.08 |

**Bayesian 底层逻辑**：1 个非常强 ≈ 2 个强 ≈ 4 个中等 ≈ 8 个支持；不同强度间为指数关系（指数底=2.0）。组合时证据**比值（Odds）相乘**，等价于积分相加：`OddsPath_total = 2.08^(净积分)`；后验概率 `Post_P = OP·Prior / ((OP−1)·Prior + 1)`。先验概率锁定 0.10（来自 BRCA1/2 错义、框内 indel 及近端剪接区变异的经验观察，Tavtigian 2018 PMID:29300386）。LP 阈值对应总 OddsPath = 81（后验 0.90），P 阈值对应后验 ≥0.99。

**判定阈值（积分制，Tavtigian 2020 PMID:32720330 官方值）** ⟦培训班⟧：
- Pathogenic：≥ +10
- Likely Pathogenic：+6 ~ +9
- VUS：0 ~ +5
- Likely Benign：-1 ~ -6
- Benign：≤ -7 或 BA1 单独成立

> 旧版本此表误写为 VUS -1～+5 / LB -6～-2，与本节下文"官方 -1"自相矛盾，2026-09 已按官方值更正。

**"至少两条证据"硬规则** ⟦培训班⟧：除 BA1 可独立判良性外，任何 LB/LP/P 分类都至少需要**两条独立证据**。只有一条证据时（如单独 PVS1 = +8，或单独 BP4 = -1），**一律 VUS**，即使积分已落入 LP/LB 区间（ACGS 2024 v1.2；Tavtigian 2020 亦注明单一 PVS1 达 8 分但 2015 组合规则要求两条）。

**已知的两个自相矛盾组合规则（高勇报告，需人工警惕）**：
1. 致病规则 (ii) 两个 Strong（+8）→ 概率约 97.5%，实际落在 LP 与 P 之间。
2. 可能致病规则 (i) 一个 Very Strong + 一个 Moderate（+10）→ 概率约 99.4%，实际已达 P 水平。

**LB 下界的稳健性提示**：净积分恰为 -1（仅一条 Supporting 良性证据）时按官方值为 LB，但已被"至少两条证据"规则挡回 VUS；净积分 -2 且唯一来源为计算预测 BP4_Moderate 时同样脆弱（Pejaver 表的 Moderate 档会把无任何致病证据的错义翻成 LB）。🤰 **产前模式强制**：良性侧仅有计算预测（无频率/功能/家系证据）时不出 LB，停在 VUS 并在模块 6 说明。

**先验概率不锁定的例外**：大 panel/健康体检者场景真实先验可 <1%（系统会高估）；高外显率 AD 基因 + 明确家族史场景先验可 >50%（系统会低估）。0.10–0.32 区间内系统仍内部一致。操作：落在这两类场景时，模块 6 须写明先验偏移方向与结论稳健性；边界分（+5/+6、+9/+10、-1/-2）时并列给出先验 0.05 与 0.32 下的后验作敏感性分析。

**分类档位敏感性分析** ⟦培训班⟧：当任一证据存在相邻两档争议（如 PS2 原级 vs PS2_Moderate）且改档会跨分类线时，报告须同时输出积分区间与两种分类（如"+9～+11，LP/P 边界"），并写明所选档位及理由。

**基因-疾病有效性上限（GUS 封顶）** ⟦培训班⟧：ClinGen/GenCC 基因-疾病有效性为 Limited、No Known Disease Relationship、Disputed/Refuted（即 GUS，意义不明基因）时，**无论证据组合如何，最终分类上限为 VUS**（ACMG 2020 声明），模块 1 标注 `Gene-disease validity cap applied`，报告须区分"GUS 中的 VUS"与"已知疾病基因中的 VUS"。Moderate 级有效性可给到 LP，但 PVS1 强度受 §1.2 表限制。

**VUS 内部亚分档（仅内部/附表，不进分类栏）** ⟦培训班⟧：VUS-High（偏致病侧，净积分 +3～+5 或有单条 Strong 以上证据但缺第二条）/ VUS-Mid（0～+2 或证据冲突）/ VUS-Low（偏良性侧，仅 -1 计算预测挡在 VUS）。Bennett 2025（151,368 变异）：VUS-High 重分类率 10.2%，VUS-Low 从未升至 P/LP。用途：VUS-High 优先安排家系/功能/RNA 验证，VUS-Low 在低先验场景可不报或移附表。**禁止**在报告分类栏写"倾向致病/接近 LP"。ACMG SVC v4.0 将标准化亚分档，届时以官方界值为准。

## 1. PVS1：功能丧失型变异（最复杂，四级决策树）

### 1.1 三个前提门槛（缺一不可 — 李茹/PVS1课件）

赋 PVS1 前必须依次确认：

1. **疾病机制确为 LOF**（见 1.2 判定法）
2. **变异确为 null 型**：无义、移码、经典 ±1/2 剪接、起始密码子、单/多外显子缺失或基因内重复、终止密码子丢失
3. **变异落在临床相关转录本的组成型外显子**：MANE Select (plus Clinical) 优先；但 MANE 不是唯一相关转录本，MANE 上的外显子不一定都是组成型——必须确认变异所在外显子无可变剪接跳跃、且在受累组织高表达（查 GTEx 组织特异表达）

**不适用 PVS1 的情形**：机制非 LOF；无证据表明 LOF 致病；无 RNA 证据的非经典剪接位点变异；可产生补救转录本的剪接变异；无 RNA 证据且 SpliceAI Δ<0.8 的 +2T>C 变异。

**互斥**：PVS1 不与 PM1、PM4、PP2、PP3 共用。

### 1.2 LOF 致病机制判定（按可靠性排序，李茹/PVS1课件）

**判定优先级：数据库证据 > 预测值**

1. **ClinGen Gene-Disease Validity**（首选）：分类为 Definitive/Strong 是适用 PVS1 原级的前提之一
   - 查询：https://search.clinicalgenome.org/kb/gene-validity ；补充 GenCC https://thegencc.org/
2. **ClinGen Dosage Sensitivity HI Score**（首选）：
   - 查询：https://search.clinicalgenome.org/kb/gene-dosage
   - **HI=3** → 充分证据，LOF/单倍剂量不足即致病机制 → 支持 PVS1 原级
   - HI=2 → 部分证据（2019-02 后评估的可考虑）
   - HI=1/0 → 证据不足
   - **HI=30** → 该基因为常染色体隐性遗传相关，绝大多数机制为 LOF
   - **HI=40** → 剂量不敏感，缺失不致病
   - HI=-1 → 不评定（如假基因）
3. **变异类型及分布**（PVS1 原级要求）：基因-疾病有效性强/明确 **且** ≥3 个 LOF 变异已在**不使用 PVS1 的前提下**被独立判定为致病（SVI 2018 原意：用来证明"LOF 是机制"的那些变异，其致病分类不得依赖 PVS1，否则循环论证——⟦培训班⟧ 旧版误读为"本例不再叠加 PVS1"，已更正）或 >10% 表型相关变异为 LOF（须分布 >1 外显子，单外显子基因除外）
4. **ClinVar/HGMD P/LP 变异类型分布**（经验证据，置于预测值之前）⟦培训班⟧：截短变异 P/LP 遍布全基因 → 支持 HI/LOF（如 TET3）；P/LP 以错义聚集为主、截短罕见 → 提示 GOF/DN（如 SAMD9），此时 PVS1 不适用。
5. **预测值（仅辅助，不可单独定机制 — PVS1课件明确警告）**：
   - pLI ≥0.9（o/e <0.35）
   - LOEUF <0.6（gnomAD v4.1；v2 时代为 <0.35）
   - pHaplo ≥0.86（DECIPHER）
   - ⚠️ **预测值陷阱**：BRCA1 明确为单倍剂量不足致病（HI=3），但 pLI=0、LOEUF=0.73。**使用预测值时必须考虑外显率、严重程度、发病年龄；晚发/轻症疾病可能不适用。**

**机制对照参考**（PMID:36806206，"孟德尔遗传-显隐性致病机制"）：
- LOF：等位基因/mRNA/蛋白丢失，最常见；多为隐性；单倍剂量不足时为显性
- GOF（功能获得）：蛋白获得异常/新功能，如 FGFR3, SOS1, MYOC, MEFV
- 显性负效应（dominant-negative）：变异干扰野生型蛋白，多聚体蛋白需重点考虑，如 COL1A2, KCTD1, GHR, POU1F1, GH1, THRB

**一基因多机制警示（PVS1课件 — 努南综合征/LZTR1 实例）**：同一基因在不同遗传模式下机制可相反。LZTR1：NS10（AD）为 GOF（变异聚集 KT1-4 域），NS2（AR）为 LOF。PTPN11：NS1（AD）为 GOF，混合性软骨瘤病（AD, HI=3）为单倍剂量不足。**判定机制前必须先锁定本例对应的具体疾病/遗传模式。** AD+AR 双模式基因约占 12.9%（王剑），近亲/ROH 家系不得只按 AR 过滤，AD 基因的纯合变异须保留评估。

**基因-疾病有效性等级 → PVS1 上限** ⟦培训班⟧（王明明/阴凯丽 MIPEP、蒋 TBX2；PMID:30192042）：

| ClinGen/GenCC 有效性 | 附加条件 | PVS1 上限 | 最终分类上限 |
|---|---|---|---|
| Definitive / Strong | 满足上文第 3 条分布要求 | 原级 (Very Strong) | 无 |
| Moderate | ≥2 个表型相关 LOF 报道（分布 >1 外显子）**且** 动物敲除重现表型 | PVS1_Strong | LP 可达 |
| Moderate | 仅满足上述其一 | PVS1_Moderate | LP 可达（需其他证据） |
| Limited / Disputed / 无 | — | 不适用 | **VUS**（§0 GUS 封顶） |

**两条前提陷阱** ⟦培训班⟧：①双等位 LOF 胚胎致死的基因在人群/患者中检不到 LOF，"无 LOF 证据"≠"LOF 不致病"，此时 PVS1 只能不适用并注明原因；②AD 基因即使有效性明确也未必是 HI 机制（可能 GOF/DN，如 COL1A2 高约束但为 DN），须按上文第 1–4 条核实。

### 1.3 NMD 预测（决定 PVS1 强度 — 李茹决策树）

决定性因素：**PTC 所在转录本和位置**

| PTC 位置 | NMD 预测 | PVS1 强度 |
|---------|---------|----------|
| 靠前或中间外显子（其余位置） | 是，被降解 | **PVS1 原级（Very Strong）** |
| 最后一个外显子 | 否（NMD 逃逸） | 按 §1.4.1 子分支定级（Strong / Moderate / N/A） |
| 倒数第二外显子最后 50bp 内 | 否（NMD 逃逸） | 同上 |
| 距翻译起始 <100bp（靠近 5'端） | 常逃逸（可用下游 AUG 重启翻译） | 慎用，功能验证或降级 Moderate/Supporting |

**NMD 机制细节（PVS1课件）**：从起始密码子前 ~100-200bp 的无义变异罕见为 NMD 靶点（可用潜在起始密码子重启）；NMD 效率在起始密码子下游前 200bp 逐渐增加。
**经典反例**：BRCA2 c.9976A>T (p.Lys3326*) 位于最后一个外显子，丢失末 93 个氨基酸但不增加乳腺癌风险，评为良性（BA1, BS3, BP5_VeryStrong）。

**操作提示（转录本坐标陷阱）** ⟦培训班⟧：DECIPHER 等工具的 NMD 逃逸区/50bp 规则可能标注在非 MANE 转录本上（PKP2：NM_004572 14 外显子 vs MANE 13 外显子），须用 CCDS/Ensembl 换算到 MANE 转录本后再判；50bp 以 CDS 坐标计。

#### 1.4.1 NMD 逃逸（无义/移码）后的子分支 ⟦培训班⟧（SVI 2018 决策树 + Walker 2023）

```
预计不发生 NMD →
  ├─ 截断/改变区域为已确立关键功能域 → PVS1_Strong（2023 起若证据充分可考虑上调至 PVS1）
  └─ 截断区功能未知 →
       ├─ 该外显子的 LoF 变异在一般人群中高频 或 外显子不在临床相关转录本 → PVS1_N/A
       ├─ 去除蛋白 >10% → PVS1_Strong
       └─ 去除蛋白 <10% → PVS1_Moderate
```
- 截断比例 = (全长 − 截断位) / 全长，以 MANE CDS 氨基酸数计（PKP2 案例：(881−852)/881 <10% → Moderate）。
- VCEP 可再按"截断区下游是否已有致病变异"细分（FOXN1 工作组）。
- "关键功能区"的证据**必须与本例疾病实体/遗传模式一致**：TET3 exon 9 的 4 个 AR-P/LP 错义不能证明该区对 AD-LOF 关键。

### 1.4 截断区重要性判断（NMD 逃逸时 — PVS1课件/李茹）

预计不发生 NMD 时，须确定截断/改变区域对蛋白功能是否重要：
1. 文献/实验确定截断区功能（关键结构域）；识别工具：InterPro、Pfam（同源域）、复合蛋白晶体结构（关键互作残基）
2. ClinVar/内部库查截断区下游是否有已报道致病变异
3. 查该区是否存在可变剪接
4. **查 VCEP 特定基因评级指南**（最高优先级）

**VCEP 实例（可上调/下调 PVS1 — 务必查 cspec）**：
- **PTEN**：起始密码子变异按通用框架为 PVS1_Moderate，但 PTEN 工作组有足够患者数据 → 建议用 PVS1。最后一个外显子虽不 NMD 但功能域关键 → p.D375 以前建议用 PVS1。
- **FOXN1**（SCID 工作组）：用已知致病变异调节 PVS1 强度；forkhead 域（aa 270-367）、transactivation 域（aa 511-563）内的非 NMD 截断 → PVS1。
- **GJB2**（Hearing loss 工作组）：仅 2 个外显子的基因 → 建议用 PVS1（PMID:30311386）。

参考工具：**AutoPVS1** https://autopvs1.bgi.com/

### 1.5 起始密码子丢失（PVS1课件）

SVI 建议：造成起始密码子丢失的变异**不应使用 PVS1 或 PVS1_Strong**，通用框架上限 **PVS1_Moderate**（功能研究表明下游甚至上游 AUG/非 AUG 可重启翻译，PMID:32209305）。

**分档表** ⟦培训班⟧（王明明/李茹 S59）：

| 情形 | PVS1 强度 |
|---|---|
| 无替代起始转录本，且 Met1～下游首个框内 Met 区间内已有 P/LP 变异 | PVS1_Moderate |
| 无替代起始转录本，该区间内无 P/LP | PVS1_Supporting |
| 存在使用替代 ATG 的**主要功能转录本**（在受累组织主要表达且功能完整，数据库/文献核实） | N/A |
| 文献证实下游 ATG 生理性重启并产生部分功能蛋白 | N/A |
| 存在可绕过 exon 1 的次要功能转录本（如 FZD4 NM_001100255.1），但非主要转录本 | 降至 Moderate/Supporting，**不直接 N/A** |
| VCEP 明确上调（PTEN；GAA Lysosomal VCEP 允许 PVS1_Strong，有酶活/WB 功能证据时上调至 PVS1 而非另计 PS3） | 依 VCEP |

- 下游 Met 若位于信号肽内，重启翻译亦无功能，可按"区间内有 P/LP"处理。
- 如与特定基因 VCEP 冲突，以 VCEP 为准。

### 1.6 终止密码子丢失（PVS1课件，ACGS 2024 v1.2）

如果存在无终止密码子降解（NSD, Non-stop decay）→ 可用 PVS1。

### 1.7 外显子缺失/重复（PVS1课件，PMID:31534211）

- **整个单倍剂量不足基因的缺失**（无冲突）→ 可直接评为 LP（**PVS1_Stand-alone**）
- 单/多外显子缺失：评估是否造成移码、是否为临床相关转录本
- 基因内重复：仅考虑**串联（in tandem）**形式（≥83% 重复为串联，PMID:25640679），评估是否移码。**Brandt 2020 分档** ⟦培训班⟧：证实串联（Gap-PCR/断点引物/断点测序）且破坏阅读框或预计 NMD → PVS1；推定串联（无断点信息）→ PVS1_Strong；非串联或性质不明 → N/A。临床可保守取 Strong（李茹 TSC1 案例）。
- ⛔ PVS1 不适用于：明确在基因外的外显子、涉及多个基因的缺失、全基因重复、串联的整个基因重复
- 外显子长度为 3 的倍数 → 推定框内跳跃，转入 §1.8"保留阅读框"分支；同时给出 SpliceAI 与 RDDC RNA Splicer 的两种可能后果。

### 1.8 剪接变异的 PVS1 框架（2023 SVI 重大更新 — 多份课件）

**🔑 2023 SVI 核心新规（PMID:37352859）**：
- 实验证实变异**引起异常剪接（LOF）** → 用 **PVS1_Strength(RNA)**，**取代 PS3**
- 实验证实变异**不引起异常剪接** → 用 **BP7_Strong(RNA)**，**取代 BS3**
- 框内 RNA 跳跃事件若涵盖无争议临床相关残基 → SVI 建议 PVS1 升级至 Very Strong；上调依据除"该域有致病错义"外，还包括"互补供体/受体二核苷酸位点存在致病变异"
- ⚠️ 仅检测 RNA 剪接改变的实验**不用 PS3/BS3**（不直接反映蛋白功能）；但进一步检测剪接后蛋白功能可同时用相应等级 PS3/BS3（吴家裕）。⟦培训班⟧ **封顶**：PVS1(RNA) + PS3 合计 ≤8 分（Moderate+Strong=6 可；PVS1(RNA)_VeryStrong 已用时不再叠加 PS3）；良性侧 BP7(RNA) + BS3 同样 ≤8。
- ⟦培训班⟧ PVS1(RNA) 吸收预测型证据：已用 PVS1(RNA) 时不再叠加 PP3/PM4/预测型 PVS1（预测只用于解释 RNA 结果的合理性）。
- 离体 RNA 前提：须确认目标基因在所取组织（血/羊水细胞等）有表达，否则 RT-PCR 阴性无意义；BP7(RNA) 仅采信非肿瘤组织；外显子变异用 BP7(RNA) 排除剪接后**仍须评估蛋白层面效应**。
- 文献 minigene 证据可信度清单：片段保留 ≥200–300bp、<6kb、WT/Mut 同片段、细胞系与疾病相关、双细胞系、质粒测序；局限：缺远端 ESE/ESS、组织特异剪接不可复现、过表达伪产物。

**剪接术语与坐标** ⟦培训班⟧：供体剪接区域 = 外显子末 3 碱基 + 内含子 +1～+6；受体剪接区域 = 外显子第 1 碱基 + 内含子 −1～−20；最小剪接区域 = 外显子第 1 碱基与 −3 位；分支点 −18～−44。BP7 的"剪接区域外"以 +7/−21 为界。

**经典 ±1,2 二核苷酸变异决策（PVS1课件 A-I 分支，⟦培训班⟧ 补齐）**：
- A：5'UTR 区无剪接改变预测 → PVS1_N/A
- B：外显子跳跃/隐匿位点消除起始密码子且无替代起始 → **PVS1**
- C：外显子跳跃/隐匿剪接破坏阅读框 + 预计 NMD → **PVS1**
- D：破坏阅读框 + 不 NMD + 截断区已确立关键 或 去除 >10% → **PVS1_Strong**
- E：破坏阅读框 + 不 NMD + 去除 <10% 且非关键区 → **PVS1_Moderate**
- F：保留阅读框 + 删除已确认关键功能区 → **PVS1**
- G：保留阅读框 + 去除 >10% 但非确认关键区 → **PVS1_Strong**
- H：保留阅读框 + 去除 <10% 非关键区 → **PVS1_Moderate**
- ⛔ **RNA 证实为框内插入**（新生受体/供体致内含子序列纳入、小片段内含子保留，阅读框保留、无序列丢失）且**无蛋白功能数据** → **记录不计分**：不赋 PVS1(RNA)，也不赋 PS3。**不得套 F/G/H 分支**——F/G/H 的前提是删除/去除序列，把"去除 0%"代入 H 得 PVS1_Moderate 是误读；上文 Very Strong 升级条款针对框内**跳跃**，同样不适用于插入。依据：Walker 2023 Fig.5 注 (5)，对 missense/框内 indel 在无蛋白功能数据时剪接数据"recording—but not applying a code"（原文针对变异本身为错义/框内 indel，此处按同一理由类推至内含子变异的框内插入后果）；异常转录本比例未知时另按部分剪接下调。插入位点落在关键结构域只说明位置重要，不等于证实 LOF。补证路径：对插入突变体做蛋白功能实验 → 按本节吴家裕条款另计 PS3（单一体外实验默认 PS3_Supporting）；PP3 在未用 PVS1(RNA) 时不被吸收，可保留。实例：WDR26 NM_001379403.1:c.823-10A>G → p.(Lys274_Ala275insPheLeuGln)，插入落在 CTLH 域（UniProt 156–231，MANE 编号 +100），稿件 2026-0186 复审，2026-09-25。
- 存在正常补救转录本 → PVS1_N/A（如 BRCA1 c.594-2A>C，框内功能性转录本天然存在，良性，PMID:27008870）
- **+2T>C**：可能形成功能性 GC-AG 剪接，无 RNA 证据且 SpliceAI <0.8 时**不用 PVS1**（PMID:32369867）
- **+2C>T**（GC 供体位点，约 1.5% 自然剪接位点用 +2C）：可能提高剪接效率 → PVS1_N/A
- EDA 三条经验（李茹）：同位点不同碱基替换的剪接效率不同；相邻内含子变异可致同一跳跃事件；顺式双突变效应更重。

**剪接预测工具与阈值（Walker 2023 SVI 校准，PMID:37352859）**：
- **SpliceAI**（金标准，AUC 0.991）：Δscore ≥0.2 → 预测发生剪接 → **PP3（Supporting，不升级）**（准确性 78%）；≤0.1 → 预测不发生 → **BP4（Supporting）**，若同时为剪接区域外的同义/内含子变异可再叠 BP7；**0.1～0.2 灰区 → 不作剪接结论**，改按错义/Indel 的蛋白层面预测处理。≥0.8 仅用于 +2T>C 例外判断与 RNA 验证优先级提示，**不抬高 PP3 强度**（剪接预测 PP3/BP4 只有 Supporting 一档，升级只能靠 RNA 证据走 PVS1(RNA)/BP7(RNA)）。窗口默认 ±500bp。**推荐用基因组坐标输入**（HGVS 因转录本左右对齐可能有误差）。https://spliceailookup.broadinstitute.org
- **PP3 对同一变异只用一次**：剪接预测与错义预测不能各计一次，取其一；外显子变异在评估剪接的同时须评估蛋白效应。
- 经实验验证的剪接变异可查 **SpliceVarDB**
- 其他工具：MaxEntScan（经典位点）、varSEAK（商业，临床报告）、MMSplice（外显子跳跃）等（详见潘丹丹工具对比）

**BP7 适用边界** ⟦培训班⟧：仅在 BP4（SpliceAI ≤0.1）成立时可用；保守性对 BP7 无帮助；仅用于剪接区域外（+7/−21 之外）的内含子/非编码变异，以及外显子第 1 与末 3 碱基之外的同义变异；**不适用于供体/受体剪接区域**。

**剪接变异的 PS1（PVS1课件/ACGS 2024 强度矩阵）** ⟦培训班⟧：先决条件——待评估变异（VUA）的预测事件须与已知 P/LP 变异**完全匹配**（如都预测外显子跳跃，或都预测用隐匿位点），且 VUA 预测强度≥比较变异；须存在同预测影响的**已确认**致病变异（PVS1(RNA)+PS1 同此要求）。可 PP3+PS1 共用、PVS1+PS1 共用、BP4+BP7 共用。

| VUA 自身证据 | 参照变异位置 | 参照为 P | 参照为 LP |
|---|---|---|---|
| PP3 级（非 ±1,2） | 同一位点不同核苷酸 | PS1 | PS1_Moderate |
| PP3 级 | 同一供体/受体基序（含 ±1,2） | PS1_Moderate | PS1_Supporting |
| PVS1 级（±1,2） | 同一 ±1,2 位（如 +2T>A vs 已知 +1G>T） | PS1_Supporting | 不赋 |
| PVS1 级 | 同区域非 ±1,2 | PS1_Supporting | PS1_Supporting |
| PVS1_Strong/Mod/Supp 级 | 同一 ±1,2 位 | PS1 | 不赋 |
| PVS1_Strong/Mod/Supp 级 | 同区域非 ±1,2 | PS1_Moderate | PS1_Supporting |

### 1.9 🤰 产前 RNA 证据获取路径（李茹 TET3 案例 + 余丽华 RYR1 案例）

产前 LOF/剪接变异若初判 PVS1_Moderate 且为关键决策点，产前独有可获得 RNA 级证据的窗口，应在遗传咨询中主动提出。⟦培训班⟧ 路径表：
1. 先查目标基因在羊水细胞/绒毛/脐血中的表达（GTEx 无产前组织，可引用本地羊水表达基线库或文献 TPM）；
2. 表达充分 → 引产前留取脐血/羊水细胞做 RNA-seq 或 RT-PCR；
3. 不表达（如 RYR1）→ 羊水间充质干细胞定向诱导（成肌/成神经等）后 cDNA 测序；
4. 已引产 → 受累组织 cDNA + 病理/电镜；有家族史者可用家族患者样本；
5. 所得结果按 §1.8 走 PVS1(RNA)/BP7(RNA)，将 PVS1_Moderate 升级或撤销。

### 1.10 PM4 / BP3 / PP2 / BP1（⟦培训班⟧ 新增，旧版缺定义）

**PM4（蛋白长度改变，Moderate）**：适用于非重复区的框内插入/缺失、以及终止密码子丢失（无 NSD 时）。默认 PM4；单氨基酸缺失且不涉已知关键残基可降 PM4_Supporting。⟦ACGS 2024⟧ **GOF 基因末外显子截短且预测/证实 GOF**（如 NOTCH2/Hajdu-Cheney）→ 用 PM4 而非 PVS1。互斥：PM4 不与 PVS1、PS1、PP2、PP3、PM5 共用（PVS1/PM4 与 PP3 同属"致病机制预测"）；无 RNA/功能实验时 PVS1/PM4 与人群数据冲突不享有高于人群数据的优先级。框内 del/dup 要用 PM5 须先满足 PM4。

**BP3（重复区框内 indel，Supporting）**：框内 indel 位于重复区（UCSC simple repeat / segmental dup / RepeatMasker 轨道）且该区无已知功能 → BP3（蒋 MNX1 c.585_593del）。BP3 不与 BP4 共用。

**PM4 / BP3 的"是否重复区"必须主动核查，不可推定（2026-09-28，CUL7 c.4126_4128del 事故）**
- 数据来源：用 `references/freq_repeat_lookup.py` 取得三项——① UCSC ±30 bp 序列（小写表示 RepeatMasker 软屏蔽）；② rmsk 与 simpleRepeat 轨道是否覆盖缺失/插入区间；③ UniProt ±10 aa 窗口及同一氨基酸的连续串长度。三项都要写进证据理由。
- 判定：
  - DNA 层命中 rmsk/simpleRepeat 或软屏蔽，**或**蛋白层同残基连续串 ≥4（例如 poly-Glu、poly-Ala）或窗口低复杂度 → **重复区**：PM4 ⛔，评估 BP3。
  - 两层都确认为非重复 → 才可评估 PM4。
  - 任一层未能核查 → PM4 与 BP3 都不赋，标注"序列上下文未核查"。
- ⛔ 禁止写"未检索到位于重复序列/低复杂度区的证据，故 PM4 适用"。没有核查过，就不能下"非重复"的结论。
- BP3 的"无已知功能"要单独论证：变异在 Pfam 结构域注释边界内**不等于**有已知功能。须结合保守性（phyloP）、该片段是否有致病变异聚集、gnomAD 中同区 indel 的耐受情况来判断。如果论证不充分，可以不赋 BP3，但 PM4 仍然不适用。
- 范例：CUL7 p.Glu1376del → rmsk `(TCC)n` Simple_repeat（chr6:43,040,314–43,040,394，hg38），蛋白 `AEG[EEEEEE]NED`（E1371–E1376），phyloP 0.184 → PM4 不适用，BP3 可以赋（需注明位于 Cullin 结构域注释范围内）。

**PP2（错义为主要机制且良性错义少的基因，Supporting）**：gnomAD Missense Z ≥3.09 可作参考；PP2 为基因级约束，**不与 PM1（结构域级约束）、PS1/PM5、PM4 共用**（Garrett 2020 / CanVIG-UK）。其他证据均指向良性时，不得用 PP2/PM2 把变异"托"在 VUS。

**BP1（截短为主要机制基因中的错义，Supporting）**：机制为 LOF 且 P/LP 以截短为主的基因中的错义变异；具体阈值按 VCEP。

## 2. 人群频率证据：PM2 / BA1 / BS1 / BS2（潘丹丹报告）

> 2026-09-29 v2：取数、状态机、落地路径与回归测试以 `FREQUENCY_EVIDENCE.md` 为权威；本节为判定规则摘要。

### 2.1 PM2（SVI 2020 降级）

- **默认降级为 PM2_Supporting**（除有专病 VCEP 规则的基因）
- 适用所有变异类型（BA1/BS1/BS2 亦适用所有变异类型）
- ⛔ **前提：gnomAD 已由 `freq_evidence.py` 按归一化坐标成功查询**（SKILL.md Step 0.45）。可赋条件只有两种：
  - `ABSENT_CONFIRMED`：REF 已核对、已左对齐、±60bp 无等价记录、Allele Registry 无 gnomAD_4 链接，且位点覆盖充分；
  - `FOUND`（至少一个数据集 PASS）且 **grpmax AF 点估计**低于 PM2 上限（AD 默认要求 AC=0）。

  `NOT_QUERIED`（包括只做过 web_search 或 ClinVar 页面检索而未命中）、`ABSENT_LOW_COVERAGE`、`ABSENT_COVERAGE_UNVERIFIED`、`REPRESENTATION_MISMATCH`、`CONFLICT`、`INVALID_INPUT` 均**不赋**。`FOUND_FILTERED`（所有数据集未通过质控，含 AC0）**不自动赋**，人工判断。"文献称 absent in gnomAD"不能代替实时查询，因为文献发表后数据库可能新增了记录。
- **AR 与 AD 的判据不同**（2026-09-29 用户确认口径）：AD 通常要求 AC=0（外显不全或迟发疾病按 Whiffin 计算并写出参数）；AR 的 **PM2 用 grpmax AF 点估计**与 PM2 上限比较，**BS1 用 grpmax FAF95** 与最大可信 AF 比较。最大可信 AF：AD = 患病率/2 × 等位贡献 × 遗传贡献 / 外显率；AR = √患病率 × 等位贡献 × √遗传贡献 / √外显率（Whiffin 2017）。PM2 上限用"典型参数"，BS1 下限用"最大参数"（ACADVL VCEP：PM2 <0.001，BS1 ≥0.0035，BA1 ≥0.007）。频率介于两者之间时两条都不赋。东亚/国人高频的奠基者等位本身不是良性证据，但会让 PM2 失效。
- ⚠️ 低覆盖区、indel 人群数据质量差时慎用
- 大缺失/重复（≥50bp）需核查 gnomAD SVs/CNVs 或 DGV (https://dgv.tcag.ca/)
- gnomAD 当前 v4.1.1/GRCh38，欧洲裔占约 3/4，东亚估计不稳；年龄分布可辅助 BS2 判断
- ⟦培训班⟧ **PP3_Strong + PM2_Supporting = 5 分 = VUS**：这是产前 novel 错义最常见的"看起来很像致病"陷阱，不得凭预测评分抬高
- ⟦培训班⟧ PM2 与 PS4 不可共用同一对照队列（有第二独立队列可合并）

### 2.2 BA1 / BS1

- **BA1**（SVI 2018）：任一 ≥2000 等位基因的大陆人群频率 >5%，且不在 BA1 豁免名单内 → 独立良性，一票否决所有致病证据
- **BS1**：频率大于疾病预期。阈值用 cardiodb 计算器估算：https://cardiodb.org/allelefrequencyapp/（输入遗传模式、患病率、等位基因异质性、遗传异质性、外显率、置信区间；第 7 参数"参考人群等位基因数"默认 121412 为 ExAC，须按所用 gnomAD 版本改；Whiffin 2017 Genet Med 19:1151）
- 注意 **BA1 豁免变异名单**（Ghosh 2018 Table 1，已核原文；以 ClinGen 在线清单为准）：ACAD9 c.-44_-41dup；ACADS c.511C>T；BTD c.1330G>C；GJB2 c.109G>A（p.Val37Ile）；HFE c.187C>G、c.845G>A；MEFV c.1105C>T、c.1223G>A；PIBF1 c.1214G>A。`freq_evidence.py` 命中时自动提示
- ⚠️ **VCEP 低阈值撞上奠基者致病变异**：GJB2 c.35delG（NFE FAF95 0.81%）、c.235delC（EAS FAF95 0.60%）都超过听力 VCEP BA1（隐性 0.5%），但都是致病变异。BA1/BS1 触发而 ClinVar P/LP ≥2★ 时，必须查 VCEP 例外说明与专家组评级后再定
- BA1/BS1 只用 grpmax 人群（afr/amr/eas/mid/nfe/sas，AN ≥2000）；ami/asj/fin/remaining 与 KOR/JPN 等小亚群不单独触发
- 有专病指南的基因用专病规则
- ⟦培训班⟧ **BA1 例外触发条件（亚效等位 / 低外显致病）**（肖锐 OCA2 p.Ala481Thr 东亚 5.27% 案例）：当同时满足 ①PM3 ≥ Strong（多例患者与致病变异复合杂合）②功能实验示部分残余活性（约 50–80%）③健康纯合子存在——**不启用 BA1 一票否决**，改用 BS1 + BS2 记录频率与纯合信息，最终输出"亚效等位 / 低外显致病（仅在复合杂合语境下致病）"类别，并在报告写明该变异纯合不致病、与 LOF 反式时致病。此类变异不在 ClinGen 官方豁免名单也可按此处理，但须在模块 6 说明依据。

### 2.3 BS2（ACGS 2024 量化）

- 早发完全外显病在健康成人中发现：隐性纯合 / 显性杂合 / X 连锁半合
- **2024 ACGS**：早发完全外显病 BS2 可用于 ≥2 个杂合健康个体（AD）或 ≥2 个纯合健康个体（AR）；晚发/不完全外显病需更多健康个体且需详细表型分析
- **gnomAD 来源的 BS2 产前默认封顶 BS2_Supporting**（2026-09-29 用户确认；VCEP 另有规定除外）：gnomAD 个体未做表型评估；CHIP 基因（DNMT3A/TET2/ASXL1/TP53/JAK2/PPM1D 等）携带者可能是克隆性造血，不作 BS1/BS2
- ⟦培训班⟧ **gnomAD 成年半合子/纯合子作为重症反证（频率"方向二"）**：早发重症 X 连锁/AR 基因，gnomAD 成年半合子（男性）或纯合子 ≥2 且排除已知亚效等位 → BS2（蒋 FLNA 7 名成年半合子 → BS2 + BS1_Supporting 压倒 PP3_Moderate → LB）。Step 1.2 取数须包含半合子计数。
- ⟦培训班⟧ **BS2/BS4 用于亲代前的四条 SOP 前置**（蒋 COL1A1 案例）：①疾病外显率高（未量化或 <~80% 时 🤰 产前一律不赋 BS2；ClinGen SVI 规定外显不全疾病不适用 BS2）②发病早 ③亲代已完成**基因特异的靶向专科评估**（如皮质发育基因→头颅 MRI；心肌病→超声心动/ECG；骨骼→X 线；仅"自述健康/常规查体"不算）且明确阴性 ④亲代 VAF 40–60%（偏离者先排除嵌合，见 §4.1.9）。四条不齐 → 不赋 BS2/BS4，在模块 6 说明。
- ⟦培训班⟧ **不构成"健康个体"的情形**（不计 BS2/BS4）：印记基因来自沉默亲本的携带者（UBE3A 父源等位脑内沉默；UBE3A VCEP 的 BS2 要求 4 名未受累携带者且变异在母源等位）；性别限制/从性表型的"不表现性别"携带者（NR5A1 46,XX）；X 连锁女性杂合携带者（XCI 随机/偏移）；外显不全疾病的携带者。

### 2.4 专病 VCEP 频率阈值（关键 — 必查 cspec）

**有专病 VCEP 规则的基因，其 PM2/BS1/BA1 阈值由 VCEP 定制，覆盖通用阈值。** CSpec 截至 2026-09-28 共 208 份规范覆盖 192 个基因（Released 123 份）；`freq_evidence.py --gene` 通过 CSpec API 自动输出 PM2/BA1/BS1/BS2/PS4/PM3 原文。实例：LDLR（FH VCEP）PopMax MAF ≤0.0002 即给 **PM2（Moderate）**，与通用 AD 规则（AC=0）结论相反

🔑 **权威查询入口**：https://cspec.genome.network/cspec/ui/svi/

代表性基因（阈值随 VCEP 更新，务必实时核对，不可硬记）：
- 心血管：MYH7, MYBPC3, TNNI3, TNNT2, TPM1, KCNQ1, LDLR, FBN1, BMPR2
- 代谢：PAH, GAA, HNF1A/4A, GCK, ACADVL, GAMT
- 眼：MYOC, ABCA4, RPE65, RPGR, RS1
- 神经肌肉：ACTA1, RYR1, DYSF, NEB, 肢带型肌营养不良相关
- 精神发育：MECP2, CDKL5, FOXG1, TCF4, UBE3A, SCN1A/2A/8A, RAS 通路基因
- 免疫：PIK3CD, CTLA4, FOXN1, ADA, RAG1/2, IL2RG
- 血液：RUNX1, VWF, F8, F9, SERPINC1, VHL

典型示例（说明量级差异，非用于直接套用）：MYH7 HCM 的 PM2_Supporting ≤0.00004，BS1 ≥0.0001，BA1 ≥0.001；耳聋 AR 基因（GJB2/SLC26A4 等）PM2_Supporting ≤0.00007，BS1 ≥0.003，BA1 ≥0.005。

### 2.5 🤰 产前频率陷阱：高频亚效单倍型（潘丹丹 TBX6 案例）

**"高频 ≠ 良性"**：某些人群高频点本身为亚效（hypomorphic）单倍型，常规流程会过滤，但与 LOF 变异**反式组合**可致病。
- 实例：TBX6 NM_004608.3 c.[-48-240A>G; -49+34G>T; 1227G>A]（T-C-A 单倍型）为亚洲人群常见单倍型，三个均为人群高频点；与 LOF 变异复合杂合 → TBX6 表达量降低 → 脊椎肋骨发育不全 5 型（PMID:25564734, 30636772, 39521787）
- **产前操作要点**：检出单杂合 LOF 变异时，主动核查是否同时存在该类高频亚效单倍型；先证者与无症状父/母基因型一致时需回访评估父/母表型（外显率/表现度问题）

### 2.5b 🤰 高同源假基因区域陷阱（符芳 GBA1 案例）⟦培训班⟧

AR 基因仅检出单杂合 P/LP/VUS 且表型高度吻合时，**必须回看 BAM**：覆盖度、MAPQ、外显子级读深缺口。基因-假基因重组（GBA1 RecNciI c.[1448T>C;1483G>C;1497G>C]、PKD1、SMN1、CYP21A2、NCF1、STRC、HBA1/2、PMS2、NOTCH2/NOTCH2NL 等）在短读长 WES 中表现为"单杂合 + 邻近外显子读深减半 + 假基因读深升高"，须 Long-range PCR / MLPA / 酶学（如 GBA 酶活）验证。落在 segmental duplication / 低 mappability 区的 SNV，未经 MAPQ、特异性 PCR、长读长或专用算法（DRAGEN CYP21A2、SMN Finder）确认者，**最终分类不得高于 VUS**，模块 1 标注 `Mappability caveat`。外院报告的变异一律先按坐标（VariantValidator）验位点、再查 MAPQ 与孟德尔一致性——旁系拷贝同名 cDNA 命名撞车（NOTCH2 c.74-1G>A 实为 NOTCH2NLR）是已发生过的实例。

### 2.6 第四版指南方向（潘丹丹 — DRAFT 预告）

ACMG/AMP 第四版拟将频率证据转为连续评分 POP_FRQ（如 MYH7 AF 0.00035→POP_FRQ_-1，AF 0.002→POP_FRQ_-6）；未检出记为 POP_FRQ_0。DAF（疾病等位基因频率）三种估算法：致病性变异法（最准）、患病率法、分箱法。

## 3. PS3 / BS3：功能证据质量门槛（吴家裕报告 + 李卓 2026-09 正式课件）

### 3.1 强度判定（OddsPath，PMID:31064749 Brnich 2019）

- 必须参照指南设阴/阳性对照，计算 **OddsPath**
- **至少 11 个对照变异**（含良性和致病）才能用"中等"强度
- 无任何变异做过功能实验时：可用已明确分类为 B/LB 或 P/LP 的变异（须机制和变异类型相关）作阴/阳性对照
- 实验最低门槛（用于评判文献实验是否够格）⟦培训班⟧：四种对照（WT、空白、阳性、阴性）+ 生物学重复 ≥3 + 技术重复 ≥3

**OddsPath 分档（Brnich 2019 Table）** ⟦培训班⟧：

| OddsPath | 证据 |
|---|---|
| > 18.7 | PS3_Strong |
| 4.3 – 18.7 | PS3_Moderate |
| 2.1 – 4.3 | PS3_Supporting |
| 0.48 – 2.1 | 不确定区，不赋 |
| 0.23 – 0.48 | BS3_Supporting |
| 0.053 – 0.23 | BS3_Moderate |
| < 0.053 | BS3_Strong |

**实验体系强度上限** ⟦培训班⟧：

| 实验体系 | 上限 | 默认起点 |
|---|---|---|
| 小鼠敲入/敲除重现人类表型 | Strong | — |
| 斑马鱼 | Moderate | — |
| 果蝇 / 线虫 | Supporting | — |
| 体外细胞/生化（单一实验、无 OddsPath 校准） | Supporting（校准充分可至 Moderate/Strong） | **Supporting** |

- 模式生物有效性核查：**同位密码子是否与人一致**（GJB2 小鼠 GTG→p.Val37Met ≠ 人 GTT→Val37Ile）；染料转移/电偶联类实验临床相关性有限不采信。
- **MAVE 数据**：MaveDB 原始分数 ≠ 证据。先查 ClinMave/VCEP 是否已校准该实验（有 OddsPath 或已被 VCEP 采纳）→ 可给 Strong；未校准 → 用该实验中已知 P/B 变异自行按 Brnich 计算 OddsPath；都做不到 → 最多 PS3_Supporting（同一变异 PS3_Strong+PM2_S+PP3=LP 与 PS3_Supporting+PM2_S+PP3=VUS，直接翻转分类）。

### 3.2 实验类型与适用性（吴家裕表）

理解疾病机制 → 评估实验适用性 → 评估实验有效性 → 确定证据强度。按蛋白类型选实验：酶（催化效率/产物量）、转录因子（荧光素酶报告/EMSA）、RNA 结合蛋白（RIP/REMSA）、受体（配体结合/下游磷酸化）、通道/转运蛋白（膜片钳/离子成像）等。

### 3.3 关键限制规则

- ⛔ **仅 RNA 剪接改变实验不用 PS3/BS3** → 用 PVS1_Strength(RNA)/BP7_Strong(RNA)（见 1.8）
- ⛔ **仅蛋白三维模型研究不用 PS3**
- ⛔ **仅蛋白表达量检测不用 PS3**（需进一步做功能相关实验）
- ✅ 免疫荧光发现功能相关定位异常 → PS3_Supporting
- **PS3 可与 PP3 共用**（功能 vs 进化保守预测，相互独立；剪接预测除外）；同理 BS3 可与 BP4 共用（剪接预测除外）
- **PS3 与 PM1**：通用框架下默认不叠加（PM1 本质是对功能的预测）；⟦培训班⟧ **有 VCEP 明确允许时以 VCEP 为准**（RASopathy VCEP 对 HRAS p.Gly13Asp 同时赋 PS3 + PM1(P-loop) + PM5_Strong），旧版"⛔ 硬互斥"措辞已放宽
- PS1/PM5 + PS3 限制合并：仅当参考变异无需功能数据即可判 (L)P 且无剪接影响
- 多个功能实验：**不累加**。一致时取验证最明确者；矛盾时机制最相关且验证最充分者可推翻其他；同级矛盾则均不采纳
- **BS3 谨慎使用**：单个实验"正常"可能未检测到特定变异的功能效应；不影响蛋白的错义/同义变异仍可能通过隐匿剪接致病
- ⟦培训班⟧ **PS3 与 BP4 方向相反时**：PS3 ≥ Strong 在手，则 BP4 至多 Supporting（或不计），并在模块 6 说明（蒋 TLR7 REVEL 0.080 案例：机械套 BP4_Moderate 会把有 Strong 功能证据的变异压回 VUS）
- ⟦培训班⟧ **患者组织功能异常 → PP4 而非 PS3**：患者来源样本同时携带 ≥2 个变异（复合杂合/纯合），功能异常无法归因到单个变异时（李卓 IARS2 案例：线粒体膜电位/ATP 下降），按 PP4 计（受 PP4+PP1 ≤+5 封顶）；能归因单变异（单杂合 AD、或 WT/突变型平行构建）才走 PS3。

### 3.4 数据来源

- **MaveDB** https://www.mavedb.org/（多重功能分析，>700 万变异效应，PMID 见课件）/ MaveMD / **ClinMave**（ClinGen 校准后的 MAVE 数据集）
- 基因专属数据库（如 The ALPL Gene Variant Database）

- 🤰 产前功能验证样本来源：有家族史用家族患者样本；羊水细胞可建株（见 §1.9）

## 3.5 PM1：关键功能域 / 突变热点（AI 最易滥用、专家最克制的证据）

> **编号说明**：本节为 PM1 专章，置于功能证据（PS3）与家系证据（PS2/PM6）之间，编号 3.5 以免改动下游章节交叉引用。
>
> **背景**：PM1 是人工评级与临床专家实操分歧最大的证据之一。许多胎儿遗传病诊断专家**极少**赋 PM1，而自动化/AI 评级却频繁赋予。根因是 AI 常基于"变异落在某结构域 + 该域保守"这一**表面模式**直接赋值，跳过了 PM1 真正的三道硬门槛与互斥核查。本节给出强制门槛、互斥规则、产前保守原则与五问自检清单。

### 3.5.1 原始定义与三道并列门槛（缺一不可）

ACMG/AMP 2015 定义：变异位于**突变热点（mutational hotspot）**和/或**关键且功能已确立的结构域（critical and well-established functional domain）**，**且该区域内不存在良性变异**。

定义内含三个**并列**要求，缺任一条即不可赋 PM1：

1. **功能"已确立"（well-established），非仅序列注释**：该结构域的功能须经**实验证实**为疾病机制核心（如酶催化中心、受体配体结合口袋、离子通道孔道区、DNA 结合界面的关键残基）。⛔ 仅凭 Pfam/InterPro/UniProt 画出的同源域边界**不满足**"well-established"——序列注释只说明"这里有个域"，不等于"这个域的功能是该病的关键机制且边界精确"。

2. **区域内无良性变异（最常被跳过的硬门槛）**：必须**主动检索 gnomAD**，确认该域内**没有**常见或已分类为良性/疑似良性的错义变异。若域内散布多个人群错义，说明该区域对错义替换有耐受性 → **不满足 PM1**。

3. **"热点"需数据支撑**：要么该位点/邻近位点有**多个独立致病变异聚集**（致病密度显著高于背景），要么是经统计验证的体细胞/胚系突变热点。⛔ 单纯"保守"不等于"热点"。⟦培训班⟧ **客观数据来源之一：gnomAD v4 Missense Constrained Regions（MCR）的 missense o/e**（潘丹丹，PMID:38645134）：0 < OE ≤ 0.2112 → 满足热点门槛可给 PM1；0.2112 < OE ≤ 0.3747 → PM1_Supporting；> 0.3747 → 不满足。按物理坐标/氨基酸位置在 gnomAD 基因页查看。MCR 只解决门槛 3，**不豁免门槛 2（域内无良性变异）**。经典正例：FBN1 EGF 域钙结合残基、NOTCH3 EGFr 半胱氨酸、COL1A1 三螺旋 Gly、GLI3 锌指域。

### 3.5.2 互斥与重复计数（AI 最易犯错处）

**PM1 本质是"基于位置的功能后果预测"**，因此与下列证据存在概念重叠，不可同时赋予：

- **PM1 与 PS3**：通用框架下默认不叠加（PS3 是直接功能实验，PM1 是对功能的间接推断，指向同一命题即重复计数，见 3.3）；VCEP 明确允许时以 VCEP 为准。
- ⛔ **PM1 不与 PVS1 共用**（见 1.1 互斥规则）。
- ⛔ ⟦培训班⟧ **PM1 不与 PS1/PM5 共用**（CanVIG-UK 硬禁止：同残基已由 PS1/PM5 计分，不再计结构域约束；VCEP 明文允许者除外）；**PM1 不与 PP2 共用**（PP2 基因级约束 vs PM1 结构域级约束，Garrett 2020）。
- ⚠️ **PM1 与 PP3 的隐性重叠**：PP3（计算预测有害）与 PM1 都可能在表达"这个位置/这种改变很重要"。ACMG 未将 PM1/PP3 列为硬互斥，可以共用，但 ⟦培训班⟧ **二者合计不超过 Strong（+4）**；临界判定时应保守：宁可保住证据独立性、舍弃 PM1，也不要人为抬高致病侧积分。

> **典型 AI 滥用模式**：变异落在"ATP 酶/激酶/解旋酶核心" + "高度保守" + REVEL 高分 → 同时赋 PM1 + PP3（甚至再加功能推断），把"该位置重要"用结构、预测两个口径各计一次。这是抬高积分、削弱稳健性的常见错误。

### 3.5.3 ClinGen VCEP 优先（PM1 的精确化与停用）

**有 VCEP 规则的基因，PM1 怎么用由 VCEP 说了算**（务必查 cspec：https://cspec.genome.network/cspec/ui/svi/）。VCEP 对 PM1 的典型处理：

- **直接停用 PM1**：部分 VCEP 认为该基因缺乏足够数据界定真正热点 → 不允许用 PM1。
- **绑定到精确氨基酸坐标**：把 PM1 限定到有实验支撑的极窄残基簇（如 RYR1 特定区段、PTEN 磷酸酶核心、RASopathy 基因特定功能位点），区域外一律不给。
- **与域内已知致病变异数量挂钩调强度**：类似 de novo 点系统，决定 PM1_Supporting 还是 PM1 原级。

通用框架在有 VCEP 时**退居其次**。

### 3.5.4 强度

- 默认 **PM1（Moderate，+2）**。
- 部分 VCEP 提供 **PM1_Supporting（+1）** 或 **PM1_Strong** 的调整（须依 VCEP 规则）。
- 通用框架下不自行将 PM1 升至 Strong。

### 3.5.5 🤰 产前保守原则

产前评级强调宁缺毋滥，PM1 尤其应保守：

1. **多数罕见病基因达不到"功能已确立"门槛**：真正实验定位的关键域集中在少数研究透彻的基因（离子通道、激酶、知名酶、胶原蛋白等）；绝大多数基因的域注释来自同源预测，功能边界模糊 → 默认不给 PM1。
2. **强制完成 gnomAD 域内良性变异核查**：产前不可跳过门槛 2。未核查 → 不赋 PM1，或降为 PM1_Supporting 并明确标注"未完成域内良性变异核查"。
3. **优先让不重复计数的证据当主干**：产前应以 PM2（频率）、PP3（预测，如 REVEL/AlphaMissense）、PS2/PM6（家系，按 4.1.5）支撑分级；PM1 仅作辅助，且与 PP3 临界重叠时优先舍弃 PM1。
4. **诚实标注**：报告模块 3 须写明 PM1 的依据、是否有 VCEP 背书、是否完成域内核查；无背书/未核查时应在模块 6 讨论该证据的脆弱性。

### 3.5.6 ✅ PM1 赋值前五问自检清单（强制）

赋 PM1 前逐条自检，**任一条答不上即不赋或降级**：

```
□ 1. 这个域的功能是【实验确立】的疾病核心机制吗？（不是仅 Pfam/InterPro 序列注释）
□ 2. 我【查过 gnomAD】，确认该域内【没有】良性/常见错义变异吗？
□ 3. 该位点或紧邻位点有【多个独立致病变异聚集】（热点证据）吗？
□ 4. 这个基因有【VCEP 规则】吗？若有，它如何规定 PM1（停用 / 限定坐标 / 调强度）？
□ 5. 我是否已用 PP3 或 PS3？若用了，PM1 是否与之【重复计数】？
```

- 全部通过 → 可赋 PM1（或按 VCEP 调强度）。
- 门槛 1/2/3 任一不满足 → **不赋 PM1**。
- 仅门槛 2 因检索受限未完成 → 可降为 **PM1_Supporting** 并醒目标注"未完成域内良性变异核查，证据强度待人工确认"。
- 门槛 5 发现与 PP3/PS3 重叠 → 临界判定时优先舍弃 PM1，保住证据独立性。

### 3.5.7 错误与正确示例

- ⛔ **错误（AI 典型）**："变异落在 SNF2 解旋酶域，该域高度保守，REVEL 0.94 → PM1 + PP3_Strong 同时赋予。" 问题：未查域内良性变异、无 VCEP 背书、PM1 与 PP3 表达同一"位置重要性"、序列注释当成"功能已确立"、合计超过 Strong 封顶。
- ✅ **正确**："变异落在已有多个独立致病错义聚集的功能域，文献/实验确认该域为催化核心，gnomAD 该域内无良性错义，且 VCEP 明确该坐标区间适用 PM1 → 赋 PM1。已用 PP3，经审查二者指向独立命题（一为致病变异聚集的流行病学事实，一为单变异计算预测），保留双证但在模块 6 说明独立性。"

## 3.6 PS1 / PM5：同位点已知致病变异（⟦培训班⟧ 新增，潘丹丹/马祎楠）

### 3.6.1 适用类型与前提
- **PS1**（Supporting→Strong）：与已知 P/LP 变异导致**相同氨基酸改变**的不同核苷酸变异。适用：错义、起始密码子、剪接供/受体基序（见 §1.8 矩阵）、ncRNA（须核苷酸替换）。
- **PM5**（Moderate）：与已知 P/LP 变异位于**同一氨基酸残基**但导致不同氨基酸改变。适用：错义、框内 del/dup（须先满足 PM4）。⛔ ±10 aa 内的邻近致病变异**不是 PM5**（是 PM1 热点门槛 3 的支撑材料）。
- 待评变异与已知变异的**表型须相同**（不同氨基酸改变可致不同表型/机制，GOF 基因尤须谨慎）。
- 错义若最可能机制为剪接 → PS1 慎用、PM5 不用；参考变异本身须无剪接影响。
- ⛔ **循环引用禁令**：已知 P/LP 变异的评级不得依赖 PS1/PM5（反例：c.34G>C 用 PS1_M(c.34G>T)，而 c.34G>T 又用 PS1_M(c.34G>C)）。列入判定前检查清单。
- PS1 本质是"借用"已知变异的临床证据，建议有独立文献/ClinVar 多提交支持。

### 3.6.2 强度分档
| 情形 | 强度 |
|---|---|
| PS1：已知变异为 P | PS1（+4） |
| PS1：已知变异为 LP | PS1_Moderate（+2） |
| PM5：已知 P，且待评 Grantham ≥ 已知 | PM5（+2） |
| PM5：已知 LP，或待评 Grantham < 已知 | PM5_Supporting（+1） |
| PM5_Strong：同密码子 ≥2 个**不同**致病错义改变（须 VCEP/SVI 支持，并核实与 PM1 独立） | PM5_Strong（+4）（马祎楠 HRAS Gly13Arg/Gly13Cys → Gly13Asp） |

ACGS 2024 的 PM5 细则（REVEL/Grantham 组合表）以原文为准。

### 3.6.3 互斥
PS1/PM5 互斥；PS1/PM5 不与 PM1、PP2、PM4 共用（§3.5.2、§1.10）；PVS1 + PM5 默认不共用，VCEP 明文允许者除外（BRCA1 c.68_69del；PALB2/BRCA2/FOXN1/ADA/DCLRE1C/IL7R/JAK3/RAG1/RAG2/IL2RG/ATM 等免疫缺陷/乳腺癌 VCEP）。

## 4. 家系与表型证据：PS2/PM6 / PM3 / PP1 / PP4

### 4.1 PS2 / PM6（De novo — ClinGen SVI 2018 量化框架 + 李茹/徐博成）

#### 4.1.0 核心范式转变（必读）

ClinGen SVI 工作组 2018 发布 *Recommendation for de novo Criteria (PS2 & PM6)*（Version 1.0, 2018-03；**Version 1.1, 2021-05 更新**——v1.1 澄清"confirmed/assumed"指**亲缘关系**而非 de novo 状态本身），将 ACMG 2015 原始的"PS2=强、PM6=中"二档定性体系，重构为**单一连续积分体系下的五档可调强度**。

**关键认识**：在 SVI 框架下，PS2 与 PM6 不再是两条独立证据，而是**同一条"de novo 证据"在不同亲缘核验状态下的两个入口**。两者共用同一套积分，只是亲缘未核验时每例权重折半。最终命名（PS2_x 或 PM6_x）取决于占主导的病例类型。

#### 4.1.1 双轴量化模型

de novo 证据强度由两个独立维度共同决定：

**轴 1 — 表型/基因疾病特异性（每例 de novo 的基础分值）**：

| 表型一致性档位 | 判定标准 | 已核验每例分值 | 未核验每例分值 |
|---------------|---------|--------------|--------------|
| **高度特异（Phenotype highly specific, single gene）** | 表型高度匹配 + 基因疾病为可识别的单一/特异表型（如甲型血友病、Rett 综合征典型表现） | **+2.0** | +1.0 |
| **一致（Consistent + 基因疾病有遗传异质性）** | 表型符合，但同表型可由多个基因致病（如有一定特征的 NDD） | **+1.0** | +0.5 |
| **广义符合（Consistent，疾病谱很宽 / 高度异质）** | 表型与基因谱仅广义吻合（如非特异"发育迟缓"、孤立软指标） | **+0.5** | +0.25 |
| **不一致（Not consistent）** | 表型与基因已知谱不符 | **0**（不适用 PS2/PM6） | 0 |

**轴 2 — 亲缘关系核验状态（决定走哪条通道、是否折半）**：
- **已核验**（trio-WES/WGS 含样本身份核验、或 STR/SNP 亲缘一致性分析）→ 走 PS2 通道，全权重
- **未核验**（仅父母 Sanger 阴性，无亲缘核验）→ 走 PM6 通道，权重折半

#### 4.1.2 五档强度积分阈值（PS2 与 PM6 共用）

将所有已报道 de novo 病例按上表权重累加为 **de novo total points**，对照下表定级：

| 累计积分 | 已核验主导 → 命名 | 未核验主导 → 命名 | Bayesian 积分 |
|---------|-----------------|-----------------|-------------|
| ≥ 4.0 | **PS2_VeryStrong** | **PM6_VeryStrong** | +8 |
| 2.0 – 3.5 | **PS2（原级 Strong）** | **PM6_Strong** | +4 |
| 1.0 – 1.5 | **PS2_Moderate** | **PM6（原级 Moderate）** | +2 |
| 0.5 | **PS2_Supporting** | **PM6_Supporting** | +1 |
| < 0.5 | 不达门槛，不用 | 不达门槛，不用 | 0 |

**两个最常被忽视的要点**：
1. **PM6 可升级，最高至 PM6_VeryStrong**——许多实验室仍把 PM6 锁死在中等档，这是误区。多例未核验 de novo 累积即可突破。
2. **单例 + 已核验 + 高度特异 = 2.0 分 = 恰好 PS2 原级**——这是"trio 阳性 + 典型综合征"的标准赋值锚点。若表型仅"一致"（异质性高），单例已核验也只到 PS2_Moderate。

#### 4.1.3 病例累积与混合计分

- **多例累积**：两例已核验 + 高度特异 = 2+2 = 4 分 → PS2_VeryStrong（错义变异借此获得相当于 PVS1 的强度，意义重大）。
- **PS2/PM6 混合**：已核验与未核验病例可在**同一总分内按各自权重累加**；报告时按主导证据类型命名，或拆分双标（如 PS2 + PM6_Strong）。
- **跨家系计数**：即使非同一家系，文献中报道的、表型符合的独立 de novo 病例均可计入总分（李茹）。⟦培训班⟧ 跨报道计数须按患者**去重**；多例 de novo 既可累进 PS2/PM6，也可改走 PS4，**同一批病例不得同时计入两者**；基因-疾病有效性 Limited/未收录时 de novo 证据封顶（NSF 案例：本例 + 一例文献产前相符新发 → 仅 PS2_Supporting）。
- ⟦培训班⟧ **AR 基因中的新发变异**（胡婷）：反式位置有已知 P/LP 时可用 PS2；该基因无其他已知 P/LP 时 PS2 强度降一级。

#### 4.1.4 先决条件与降级/失效情形

**先决条件（缺一即不可用）**：患者表型必须与疾病基因已知表型谱相符（轴 1 ≠ "不一致"）。表型完全不符 → 0 分 → 不能用 PS2/PM6，**即便分子上确为 de novo**。例：骨骼发育基因的 de novo 错义不可挪用到纯神经发育表型患者。

**需取消或下调赋值的情形**：
- 后续证实样本错配 / 非亲生 → de novo 前提崩塌，PS2/PM6 撤销
- 发现父母低比例嵌合 → 严格意义不再是 de novo；降为"父母嵌合传递"（部分实验室计 PP1_Supporting 或不计），需评估再发风险
- **父母 Sanger 假阴性陷阱**（PM6 最易高估处）：必须确认父母测序对该位点的技术覆盖（深度、引物覆盖、嵌合检出下限），否则"父母阴性"不可靠

**文献计数分界（徐博成 docx）**：文献写明亲缘确定或 trio-WES/WGS 检出 → 计 PS2 通道；否则计 PM6 通道。

**特殊情况（李茹）**：
- X 连锁：男性患者半合变异遗传自未患病杂合母亲，若母亲该变异为新发且家族史支持 → 可用 de novo 逻辑
- 生殖腺嵌合：父母阴性但多个患病同胞 → 须先确认亲子关系才能用 de novo
- ⟦培训班⟧ **传递亲代"隔代新发"**（胡婷病例 4）：变异遗传自无症状亲代，向上追溯祖代 + STR/SNP 亲缘核验证实在该亲代为新发 → 可按"传递亲代新发"计入 PM6/PS2 通道，表型档位取亲代+后代一致性，通常 PS2_Moderate（降一级）；仍受 4.1.6 约束不叠加 PP4。

⟦培训班⟧ **胎儿合子后嵌合的 de novo（第四道门）**（蒋 FBXW7 案例，VAF 显著偏离 50%）：①核实 MAPQ/链偏斜/重复序列排除伪影；②判据：VAF 二项检验偏离 0.5 或 95%CI 不含 0.5；③PS2 强度**保留不升档**；④表型比对降权（嵌合的组织分布决定表型器官选择性）；⑤再发风险改写为"合子后事件，亲代生殖腺嵌合上限按双亲 alt 读段 0/N 估算"，不写"~1%"。

#### 4.1.5 🤰 产前 de novo 表型特异性分级决策表（产前模式专用）

> **设计动机**：产前胎儿表型尚未表达（认知/行为/癫痫/代谢等"看不见"），超声仅能捕捉结构与生长参数。直接套用产后综合征的"高度特异"档位会系统性高估 PS2/PM6。本表给出产前阶段表型一致性档位的保守判定规则。

**第一步：判断产前可见表型与基因疾病的对应关系**

| 产前情形 | 表型一致性档位 | 已核验赋值 | 未核验赋值 | 说明 |
|---------|--------------|-----------|-----------|------|
| 超声见**高度特异**结构标志，且该标志对应**单一基因病**（如 TSC2 + 心脏横纹肌瘤；ARPKD 典型双肾改变 + PKHD1） | 高度特异 | PS2（单例 2.0） | PM6（单例 1.0） | 仅极少数"结构表型↔单基因"强绑定情形 |
| 超声见结构异常，**符合**基因谱但该表型**多基因可致**（如孤立 CHD、孤立 NTD、孤立侧脑室扩张） | 一致（异质） | PS2_Moderate（单例 1.0） | PM6_Supporting（单例 0.5） | 产前最常见的"中间"情形 |
| ⟦培训班⟧ 超声见结构异常组合，且**该基因已有 ≥1 例文献报道的胎儿期相同结构表型**（"基因 AND fetus/prenatal"检索命中，须写明 PMID） | 一致（基因特异） | 可升至 PS2 原级（单例 2.0） | PM6（单例 1.0） | 李茹 KIDINS220 案例（透明隔腔不清+侧脑室扩张+胼胝体发育不全，PMID:32909676）；升档致 VUS→LP 时须在模块 6 讨论脆弱性 |
| ⟦培训班⟧ 引产后尸检/外观/影像见综合征**特异体征**（如 CdLS 的连眉、浓眉、上唇薄、多毛） | 按产后标准定档 | 可至 PS2 原级 | PM6 | 阴凯丽 NIPBL 案例 |
| 超声仅见**非特异软指标或生长偏离**（如单纯头围偏小、单纯股骨短、单纯 NT 增厚、单脐动脉），与神经发育基因仅广义相关 | 广义符合 | PS2_Supporting（单例 0.5） | **0.25，多数不达门槛** | 单例未核验时几乎无有效证据 |
| 胎儿**无任何结构/生长异常**（变异为偶然发现 / 扩展性检测检出） | 不一致 / 无表型 | **不赋 PS2/PM6** | 不赋 | 无表型锚点，de novo 不能单独提供表型特异性 |

**第二步：产前专项调整原则**

1. **产前"高度特异"门槛极高**：仅当结构标志本身对某单基因病有近乎特异的指向时才可用（参 4.4 符芳 PP4 产前案例）。绝大多数产前表型应落在"一致（异质）"或"广义符合"。
2. **非特异生长参数不升档**：头围、股骨、腹围等单一生长偏离（如 −1.7 SD 头围）属"广义符合"上限，不可当作"高度特异"——这类参数的病因极度异质（家族性、胎盘、染色体、单基因、正常变异均可致）。
3. **产后表型出现后可回溯升档**：若继续妊娠、出生后出现基因特异性表型（如 PMNDS 的言语迟缓/癫痫/行为障碍），表型一致性档位可由"广义符合"回溯升至"一致"乃至"高度特异"，相应把 PS2/PM6 从 Supporting 推到原级/VeryStrong。应在咨询中提示家系此动态。
4. **优先用分子证据撑分级**：产前阶段 de novo 表型证据天然受限时，应让 PP3（计算预测，如 REVEL/AlphaMissense）、PM1（结构域）、PM2（频率）等不依赖表型的证据成为分级主干，de novo 作为辅助。
5. **诚实记录档位选择理由**：报告模块 3 须写明本例落在哪一档及依据，避免事后争议。
6. ⟦培训班⟧ **"尚未出现"≠"不一致"**（蒋 PTPN11 案例）：胎儿表型须先与该基因**已报道的胎儿期表型谱**核对（Step 0.7 P0），并按 HPO 三态标注（存在 / 不存在 / 本孕周不可评估）；仅当胎儿表型与已报道胎儿谱**方向相反**时才计"不一致"。
7. ⟦培训班⟧ **非特异表型也可选择暂不赋 PS2**（胡婷 NIPBL 案例做法）：产前仅非特异软指标时，"PS2_Supporting（0.5）"与"暂不赋、待生后重分析"两种做法均可，须在模块 3 写明理由；若 0.5 分不改变分级，倾向不赋以避免争议。

**产前 de novo 计分速查**：

```
单例胎儿 de novo：
  亲缘已核验 + 高度特异结构标志(罕见)        → PS2          (2.0 → +4 Bayesian)
  亲缘已核验 + 一致(多基因可致的结构异常)    → PS2_Moderate (1.0 → +2)
  亲缘已核验 + 广义符合(非特异软指标/生长)   → PS2_Supporting(0.5 → +1)
  亲缘未核验 + 高度特异结构标志(罕见)        → PM6          (1.0 → +2)
  亲缘未核验 + 一致                          → PM6_Supporting(0.5 → +1)
  亲缘未核验 + 广义符合                      → 0.25，不达门槛(0)
  无任何胎儿表型                             → 不赋 PS2/PM6
```

#### 4.1.6 🔑 PS2/PM6/PS4 与 PP4 不叠加（ACGS 2024 — 徐博成/符芳）

> If PS2/PM6 is applied, the specificity of that patient's phenotype to the relevant disorder should be captured using an **increased strength of PS2/PM6**, rather than applying a separate and additional line of evidence within PP4.

即：用 PS2/PM6 时，表型特异性已通过 4.1.1 轴 1 计入 de novo 强度，**不再单独叠加 PP4**，否则同一份表型证据双重计数。产前场景尤须警惕（产前 PP4 本就受限，见 4.4）。⟦培训班⟧ 同理：**用了 PS4（病例计数/病例对照）也不再给 PP4**（同一患者/队列用于 PS4 计数后不再用于 PP4；FBN1 VCEP 满足 Ghent 用于 PP4 的患者不能再计 PS4；F9 VCEP 同）。PP4 只留给没有新生证据、没有人群证据、但表型极其特异的病例。亲代自身新发计入 PM6 时同样受本条约束。**PP4 可与 PM3、PP1 叠加**（受 +5 封顶，且 PP4 不能重复使用已用于定义 PM3/PP1 的亚表型要素）。

#### 4.1.8 亲代传递变异的处理 ⟦培训班⟧（余丽华 TUBB 案例、蒋 COL1A1 案例）

1. 遗传自"健康"亲代 ≠ 良性证据：在对亲代做**基因特异的靶向表型评估**之前（见 §2.3 四条 SOP），不得赋 BS4/BS2，也不得据此降级；
2. 亲代靶向评估阳性（即使亚临床，如头颅 MRI 细微改变）→ 亲代计为受累者，可计入 PP1 共分离（按减数分裂计数）与 PP4（受表型特异性限制）；
3. 亲代变异经祖代检测证实为**亲代自身新发** → 按 4.1.4"隔代新发"计入 PM6/PS2；
4. **亲代 VAF 核查**：亲代 VAF 在 40–60% 之外时须做二项检验 + 排除 indel 参考偏倚，判为亲代体细胞嵌合（蒋 COL1A1 母亲四路径 VAF 24.1/21.0/24.6/27.4%，P=4.2e-8）→ BS2/BS4 不可用；再发风险介于"新发经验值"与"50%"之间，写区间并建议多组织定量；
5. 咨询：亲代亚临床 + 后代重症 = 表现度谱宽，预后措辞按 SKILL 报告措辞规范。

#### 4.1.9 嵌合 ⟦培训班⟧（王剑）

- 分类：体细胞嵌合 / 生殖腺嵌合 / 两者兼有 / 限制性胎盘嵌合（CPM），对再发风险含义不同；
- **至少两种技术检出才确立嵌合**（如 NGS + 数字 PCR/深度扩增子），单技术检出须结合超声谨慎解释；
- 先证者外周血低 VAF（<20%）的表型匹配基因变异**不得因软件 cutoff 被丢弃**，须手动 pileup 并正交验证；
- 亲代嵌合评估须写明检测 LOD（Sanger >10–15%；NGS 视深度 ~1%）；
- 嵌合变异的 ACMG 评级与非嵌合相同，但报告须单列 VAF 与组织来源；再发风险按 §4.1.8 第 4 条。

### 4.2 PM3（反式证据，AR 疾病 — ClinGen SVI PM3 点表，⟦培训班⟧ 胡婷/余丽华/李茹）

**SVI PM3 积分表**（https://clinicalgenome.org/site/assets/files/3717/svi_proposal_for_pm3_criterion_-_version_1.pdf）：

| 对侧等位基因 | 相位 | 每例先证者分值 |
|---|---|---|
| P/LP | 反式已确定（父母来源/长读长/读段定相） | 1.0 |
| P/LP | 相位未知 | 0.5 |
| 纯合（非近亲、非 ROH 内） | — | 0.5（纯合病例合计上限 1.0） |
| VUS | 反式已确定 | 0.25（VUS 病例合计上限 0.5；不得对同一对变异互相计满） |
| VUS | 相位未知 | 0 |

累计：0.5 → PM3_Supporting；1.0 → PM3；2.0 → PM3_Strong；4.0 → PM3_VeryStrong。

- 前提：待评变异与对侧变异均足够罕见（满足 PM2）；避免证据循环（对侧变异的评级不得依赖本变异的 PM3）；对侧变异升级后须重算本变异 PM3。
- **变异自身人群频率高时 PM3 须封顶**（GJB2 V37I：131 例复合杂合仍只给 Moderate）。
- **AR 病用 PM3 不用 PS4 计罕见病例**；PM2 不适用的常见隐性变异（如 GJB2 c.109G>A）才考虑 PS4（按纯合/复合杂合**基因型**在患者 vs 对照中的富集，OR>5）。
- **单亲定相推断**：父亲不可检，变异 A 母亲野生型（附近无可用 SNP）+ 变异 B 母源 → 推定反式，可赋 PM3（须注明未排除 A 为新发且与 B 顺式的小概率）；能做读段/SNP 定相则优先。
- **单人多变异**（USH2A 四变异案例）：同基因多变异必须用亲属或长读长定相，禁止仅凭 ClinVar 评级组合判定复合杂合。
- 本地病例库的第二家系同变异纯合 + 表型高度相符 → 可按上表计入 PM3（标注 `Local cohort evidence (unpublished)` 与病例数）。
- **文献 in trans / unknown 判定（徐博成 docx）**：文献写明复合杂合、in trans、或有父母来源 → 认为 in trans；否则认为 unknown。
- PM3 与 PP1：若"反式鉴定"已用于共分离评估，二者不可同时计数；PM3 与 PP4 可叠加但 PP4 不得重复使用 PM3 已定义的亚表型要素。

### 4.3 PP1 / BS4（共分离 — 符芳 ClinGen 2024 + 胡婷计数规则）⟦培训班⟧

**计数规则（ClinGen Gene Curation SOP；Zhang 2020 Curr Protoc Hum Genet 106:e98）**：
- 分离计数按**减数分裂次数**，不按家系成员数；一般情况 = 携带变异的受累个体数 − 1；多个家系分别计算后 LOD 累加。
- 计入：基因型+且表型+的个体；肯定携带者（obligate carrier）即使无表型也计入。
- 不计入：有表型未检测者；有变异无表型者（不计入 PP1，但在完全外显病中构成 BS4 反证）。
- AR：父母基因型不明 = 顺反式不明，要求父母检测；携带者父母不计入；非共分离成员通常是先证者同胞；父母一方患病另一方携带者时 0.25/0.75 概率均替换为 0.5。
- XLR：女性肯定携带者计入；男性有变异有表型计入；男性传给女儿不计入；女性未受累杂合携带者不作反证（XCI）。
- 印记基因（UBE3A 等）：只计表达亲本来源的传递；无症状沉默亲本传递不作非共分离。

**LOD → PP1 强度（Jarvik & Browning 2016, AJHG, PMID:27236918；本技能默认标尺）**：

| 减数分裂次数 | LOD（≈ n·log10 2） | PP1 强度 |
|---|---|---|
| 3–4 | 0.9–1.2 | PP1_Supporting |
| 5–6 | 1.5–1.8 | PP1_Moderate |
| ≥7 | ≥2.1 | PP1_Strong |

> 旧版 SKILL 用 LOD 0.6/1.2/2.4 三档且无出处，2026-09 改为上表。胡婷课件"5 次共分离 LOD 1.5 → PP1_Strong"引用的是基因-疾病有效性评分表，与变异级 PP1 层级错位；本技能按 Jarvik 取 Moderate。VCEP 另有规定时以 VCEP 为准；报告须声明所用标尺。

- **ClinGen 2024 新规**：多基因座异质性疾病需将 PP1/BS4 证据分摊到每个候选基因/病例（`PP1_gene = PP1_raw × 基因贡献占比`，USH2A 占 RP 30% → 2 分折为 0.6 分 Supporting）
- **PP1+PP4 合计单变异封顶 +5 分**
- ClinVar 提交者引用的**未公开内部共分离/病例数据**（无法独立复现）不计分，仅在模块 4 记录（蒋 FGD1 案例）。

**BS4 四道门槛** ⟦培训班⟧：①证据形式是"受累家庭成员中未检出该变异"，而非"无表型成员检出该变异"（后者归 BS2）；②须先确认其他受累成员所患确为与先证者**相同**的遗传病，而非仅临床表型相似；③高遗传异质性/高拟表型常见病（癌症、癫痫）易造成假性不共分离；④🤰 产前胎儿表型不完整，几乎不可能满足 BS4。可赋 0 而非反证的例外：表型模拟、表现度、外显率、临床检查不充分、印记、限性遗传、嵌合、隐性遗传。

### 4.4 PP4（表型特异性 — 符芳报告，ClinGen 2024 重大更新）

**ACMG 2015 定义**：患者表型/家族史高度特异于某单基因病。
**2017 解读四条件**：①检测灵敏度高 ②明确综合征症状（如戈尔林综合征）③该基因良性变异不多 ④家族史符合遗传方式。

**🔑 ClinGen 2024 路径（符芳）**：
- **路径1 单基因病（基因座同质）**：评估诊断率 → 直接赋 PP4 到该基因变异 → **单变异 PP4 上限 +5 分**
- **路径2 多基因病（基因座异质）**：同表型对应多个致病基因 → **按比例分摊 PP4 权重** + 加 PP1/BS4 共分离 → 单变异封顶 +5 分

**诊断率 → PP4 强度（ACGS 2024）** ⟦培训班⟧：

| 该表型在该基因的诊断率 | PP4 强度 |
|---|---|
| ≥50% | 可考虑 Strong（上限 +5，VCEP 如 FBN1 满足 Ghent 标准封顶 +5） |
| 10–50% | 通常 Moderate |
| <10% | Supporting，甚至不用 |

高诊断率是充分条件而非必要条件，仍须经基因座异质性校正；🤰 产前须用**产前队列**诊断率，无产前数据时降一档或不用。

**路径 2 分摊三步法** ⟦培训班⟧：①查该表型的总诊断率（如 HCM 全部致病基因合计约 60%）；②查该基因贡献占比（MYH7 约 33%、MYBPC3 15–20%；来源 GeneReviews / ClinGen GCI / OMIM / 文献 / 产前队列）；③`PP4_gene = PP4_total × 占比`（60% 对应 Strong 3–4 分 × 33% ≈ 1–1.5 分 → Supporting–Moderate）。四维度检查：致病基因数量 → 贡献度分布 → 表型定义粒度 → 家系共分离修正。模块 3 输出须写明：HPO 集合、诊断率数值与出处、基因座异质性判断、分摊比例、是否与 PS2/PM6/PS4 冲突、所用框架版本（ACMG 2015 / ACGS 2024 / ClinGen 2024 / VCEP——同一变异 IDS 按 2015 为 PP4_Moderate、按 ACGS 2024 为 PP4_Strong）。

**VCEP PP4 实例**：FBN1（Ghent 满足 = +5 封顶，儿童 Ghent 状态动态随访，不重复用于 PS4）；F8/F9（临床诊断依赖单一实验室指标 FVIII:C/FIX:C，PP4 常被 PS3 替代；F9 须完成全基因测序 + 缺失/重复分析才可用 PP4）。有 VCEP 时直接采用其规定强度，不自行估算诊断率。

**其他 PP4 来源** ⟦培训班⟧：①患者来源细胞的疾病机制特异功能异常在无法归因单变异时计 PP4（见 §3.3）；②复发家系中前一胎/同胞的已证实表型可并入 HPO 集合（须确认为同一遗传病，参 BS4 门槛②）；③表型驱动分析只能捕获约 71% 主要发现、5.3% 次要发现，典型异常仍 20–40% 漏检——表型驱动不能替代全外显子层面无偏分析；多条表型标准 ≠ 更高诊断率（孤立短长骨单条标准诊断率 58.3%）。

**🤰 产前 PP4 局限（符芳 — 产前最关键警示）**：
1. HPO 仅约 10% 词条适用产前；产前多为非特异结构异常，无法获取面容/神经行为/代谢特征
2. 基因座异质性普遍：骨骼发育不良、先心病、中枢畸形多基因可致；产前 HPO 词条常匹配多基因多病
3. 胎儿期外显率不明确，产前表型可能无法识别
4. 家族史常不完整/不可靠（父母表型可隐匿）

**🤰 产前 PP4 五原则（符芳个人思考，建议纳入产前模式）**：
1. **宁缺毋滥**：无明确疾病对应、无 HPO 绑定基因时不强行赋 PP4
2. **不盲套产后**：产前"特异表型"不等价高基因阳性率，盲套产后诊断率致 PP4 虚高
3. **保持怀疑**：单一超声表型背后常隐藏多基因甚至非遗传病因；基因座同质假设是最危险陷阱
4. **权重分配保守**：多基因候选时按 ClinGen 比例分配 + 封顶 +5，不全压单基因
5. **多学科协作**：超声精准描述 → 临床匹配 HPO → 实验室判断 PP4 适用性，形成闭环

**PP4 产前案例分级参考（符芳）**：
- PKHD1 复合杂合 + ARPKD 典型超声（双肾增大、回声增强、皮髓质不清、羊水过少）→ 可用 PP4
- PKD1 + 多囊肾家族史 5 代共分离 → PP1_Moderate + PP4
- TSC2 + 心脏横纹肌瘤（高度特异）→ TSC 31%/69% 归因 TSC1/TSC2（GeneReviews），文献家系分离 5 次 → PP1_Moderate（本技能 Jarvik 标尺）或 PP1_Strong（+4，课件口径），仅检出 TSC2 → PP4 按占比折算约 +1；PP1+PP4 合计封顶 +5（旧版误写"PP1=+5"，PP1 单项上限为 Strong +4）
- COL1A1 新发 + 成骨不全 → **用 PS2/PM6，不叠加 PP4**
- GLI3 新发 + 轴前多指/并趾（HP:0001177/HP:0001770）→ 新发用 PS2
- ⟦培训班⟧ 蒋宇林立场（更严）：产前 PP4 "近乎不可用"，建议**不折算分值、在报告中显式陈述表型吻合度**。本技能折中：保留五原则允许的计分情形，但产前报告**强制增加"表型吻合度陈述"字段**（落在谱内且特异 / 落在谱内但不特异 / 未报道 / 方向相反），且产前 PP4 计分优先限于 VCEP 明确定义胎儿表型条目（如 RYR1 四项）的情形。

**产前 HPO 标准化（符芳）** ⟦培训班⟧：以 HP:0001197（产前发育异常）分支为检索锚点（PMID:35872606）；关键词提取规则——"解剖结构 + 形态改变"才是关键词，程度性描述与诊断结论不是；五步转化（超声原文 → 关键词 → HPO 词条（CHPO 本地库）→ Phenolyzer/Exomiser 基因优先级 → 补充发病孕周、羊水、家族史、生长参数）；HPO 三态标注（存在 / 不存在 / 本孕周不可评估）。

### 4.5 🤰 产前表型的根本局限（李茹）

产前超声是**结构筛查工具，非功能预测工具**。
- "能看见"（结构表型）：宏观畸形、生长参数、部分软指标
- "看不见"（功能/微观/迟发）：脑功能与认知（智力/ASD/精神行为）、代谢功能（多数代谢病胎儿期无结构异常）、感官（耳聋/视网膜病变）、肌肉运动、免疫血液、迟发病
- 后果：表型相关证据链（PS2/PM3/PP4）在产前使用受限；胎儿表型动态变化难做基因型-表型关联

**产前文献检索策略（李茹）**：基因 AND prenatal / 基因 AND fetus / 基因 AND HPO表型 [Title/Abstract]。即使待评估病例表型不相关，文献报道新发病例符合疾病特征也可计入 PS2/PM6 病例数。

### 4.6 BP2 / BP5（⟦培训班⟧ 新增，旧版无定义）

- **BP2**（Supporting）：显性完全外显病中与已知致病变异**反式**、或任意遗传模式下与已知致病变异**顺式**检出，且该致病变异足以解释表型。例外：修饰变异顺式；复杂等位基因（GAA p.[S251L;S254L]）。BP2 不与 BS2（隐性语境纯合 vs 杂合）、BP5 共用；"反式鉴定"已用于抗共分离（BS4）时不再计 BP2。
- **BP5**（Supporting）：已找到其他分子病因的病例中检出。BP5 不与 BP2 共用；不可对同一被检者既作非共分离解释又作替代病因。
- 🤰 **产前 BP2/BP5 默认不赋**（蒋）：产前表型不完整，"已有解释"的判断本身不可靠；双重诊断并不罕见（KMT2E 队列中一例 PTEN 双重诊断），**找到致病变异后寻找不停止**。

### 4.7 X 连锁与性别相关模式（⟦培训班⟧ 王剑、韩瑾、蒋）

- XLR：女性杂合"无表型"母亲不构成 BS4/BS2（XCI 随机/偏移），需 XCI 分析或靶向表型评估后再判；女性发病可由 XCI 偏移解释，不得因此否定变异；共分离计数按 §4.3 XLR 规则。
- XLD：男性半合致死（MECP2 经典型）或女性限性（PCDH19）——男胎/女胎的预后与再发风险不同，模块 8′ 须按胎儿性别分写；产前基因为 X 连锁且性别未知时，模块 8′ 首条行动固定为"明确胎儿性别"（TLR7 父源半合 → 女胎 100% 携带）。
- 限性/从性遗传：对"不表现性别"的携带者不计 BS2/BS4。
- X 连锁 VUS：定向追问母系男性远亲（表舅等）并采血验证（胡婷病例 1）。
- 半合子 BS2 计数按 §2.3。

### 4.8 印记基因与 UPD（⟦培训班⟧ 王剑、蒋 UBE3A）

1. 变异位于印记基因（UBE3A、MAGEL2、SNRPN 区、CDKN1C、GNAS、KCNQ1OT1 区、MKRN3 等）时，**必须先确定亲源**；
2. 来自沉默亲本的传递 → 携带者无表型，不构成 BS2/BS4，也不作"不外显"证据；来自表达亲本 → 才评估共分离与 PS2/PM6；
3. 再发风险按传递亲本性别给出（MAGEL2 父传 50%；母传后代不发病但其子代男性可发病）；
4. WES 见 AR 纯合变异伴大段 ROH 且父母仅一方携带 → 疑 iUPD，须 SNP-array/trio 核查并联想该染色体的印记疾病；
5. 产前印记疾病检测须多技术联合（MS-MLPA 甲基化 + SNP-array + 测序），单一技术阴性不排除。

### 4.9 AR 病仅检出单一 P/LP 时的第二打击强制搜索（⟦培训班⟧ 王剑、符芳）

按序排查并在报告列出结果：①外显子级 CNV（读深/split reads；WES 推断者须正交验证 MLPA/qPCR）；②深内含子/非经典剪接（SpliceAI 全基因扫描）；③高频亚效单倍型（§2.5 TBX6 范式）；④相位（trio/长读长）；⑤同源区/假基因掩盖（§2.5b）；⑥若仍单杂合 → 报告写"携带状态，不构成诊断"，并按 SKILL 报告取舍规则决定报/不报。

### 4.10 双重诊断、双基因与修饰基因（⟦培训班⟧ 王剑、蒋）

- 多基因多变异时每个变异独立评级；PP4 只按该基因能解释的**那部分表型**赋值，不因整体表型不像单一综合征而扣分；
- 两基因均达 P/LP 且表型互补 → 报告"双重诊断"，再发风险分别给出；
- 双基因/三等位/修饰基因组合（DIDA 收录）不能用单基因框架把每个成分强推到 P，报告为"双基因模式候选"并说明证据；SNV + CNV 组合按 TBX6 范式。
- 群体分层数字不套用于 n=1：引用队列比例前核对是否含同变异个体（KMT2E 男性癫痫 5% = 1/19 恰为本例）。

### 4.11 🤰 产前样本前置质控：母体细胞污染（MCC）（⟦培训班⟧ 蒋、王剑）

- 每例产前样本**强制定量 MCC**（STR 或 WES-VAF 算法），判读前准入阈值 5%；MCC ≥20% → 该样本基因型判定与本报告置信度降为 Low，建议重采样。
- 胎儿"杂合"变异若母亲同为杂合且胎儿 VAF 偏离 0.5，先排除 MCC 再谈遗传来源；MCC 未定量时 PS2/PM6 与 de novo 判定标注"未排除 MCC"，模块 1 Confidence 下调。
- 报告模块 2 增加 `MCC status:` 行。

### 4.12 不适用本框架的变异类型（⟦培训班⟧ 王剑）

- **重复扩展/动态突变**（FMR1、HTT、DMPK、ATXN 系列等）：不适用 ACMG SNV 框架，按各病重复数阈值（正常/中间/前突变/全突变）与遗传早现规则解读；常规 WES/短读长不能可靠检出，须提示专用检测（TP-PCR/Southern/长读长）。
- **线粒体基因组变异**（m.xxxx、MT-xxx、chrM/MT 坐标）：须按 ClinGen mtDNA 专项规范（McCormick 2020）评级——PS2/PM6、PS1、内含子条目不适用；BA1 仅对确认单倍型标记；PP3 用 mtDNA 专用工具（MitoTIP、APOGEE）并排除单倍型多态；异质性水平、组织来源、检测方法 LOD（Sanger >10%，NGS ~1%）为必填。**本技能尚未内置 mtDNA 规则文件**，遇到时须先取得 McCormick 2020 原文逐条核对，不得套用本文件。

## 5. PS4：病例-对照证据（高勇报告）

### 5.1 队列构建

- Case：精确可重复的表型定义
- Control：人群匹配（尤其种族/祖源），避免人群分层假阳性
- 来源：前瞻队列（理想）/ 现有库（gnomAD、UK Biobank，须基因分型质量、测序深度、变异调用流程一致）/ 文献汇总（注意异质性）

### 5.2 强度判定（LR 优于病例计数）

**ACMG 2015 原始**：OR >5 且 95%CI 下限 >1 → 可考虑"强"；Fisher 精确检验算 P 值。

**基于似然比（LR）的分级（高勇，推荐）**：

| LR 范围 | 证据点数 EPs | 指向 | 传统强度 |
|---------|------------|------|---------|
| ≥350.4 | ≥8 | 致病 | 极强 |
| 18.72–350.4 | 4–8 | 致病 | 强 |
| 4.33–18.72 | 2–4 | 致病 | 中等 |
| 2.08–4.33 | 1–2 | 致病 | 支持 |
| 0.23–0.48 | -1~-2 | 良性 | 支持 |
| 0.053–0.23 | -2~-4 | 良性 | 中等 |
| 0.00285–0.053 | -4~-8 | 良性 | 强 |
| ≤0.00285 | ≤-8 | 良性 | 极强 |

LR 计算器：https://turnbull-lab.shinyapps.io/ps4_lrcalc/ ；BayesQuantify 亦可计算 LR。OR 计算器：http://www.hutchon.net/ConfidOR.htm 、https://www.medcalc.org/en/calc/odds_ratio.php 。样本量估算：https://www.openepi.com/SampleSize/SSCC.htm（样本量决定 LR/EP 置信区间宽度，报告 PS4 时同时给出 LR 的 CI）。

**case-control 质量门槛** ⟦培训班⟧：不同文献的 case/control 不可相加；control 须实际对该变异做了基因分型；PM2 与 PS4 不可共用同一对照队列；PS4 若用病例计数且表型纳入病例定义 → 不再叠加 PP4（§4.1.6）。

### 5.3 先证者计数法（无对照时，⟦培训班⟧ 潘丹丹/韩瑾）

前提：AD/XL 疾病；变异满足 PM2（罕见）；先证者表型相同。通用参考分档（耳聋 VCEP Oza 2018，PMID:30311386；其他基因先查 VCEP）：

| 无关先证者数 | PS4 强度 |
|---|---|
| ≥15 | PS4 |
| 6–14 | PS4_Moderate |
| 2–5 | PS4_Supporting |

三注意：①同一变异须关联相同疾病才可叠加；②同一家系算 1 例；③不同文献中同一先证者不可重复计。锚点：FGFR3 p.Gly380Arg 58 例 → PS4（PMID:25614871）；SHOC2 p.Ser2Gly 7 例 → PS4_Moderate（PMID:23918763）。与 PS2/PM6 的病例不得重复计数（§4.1.3）。AR 病不用本法，走 PM3（§4.2）。

**🤰 中国人群数据缺口**：gnomAD 等公开库缺足够高质量中国人群数据（v4.1 joint EAS 约 AN 44,850），PS4 在中国产前场景应用受限，建议建本土队列。可程序化的东亚补充是 dbSNP 各研究频率（TOMMO/Korea4K/KOREAN/部分 ChinaMAP，`freq_evidence.py` 自动列出）；ChinaMAP 需登录，只有常染色体且不含 LCR 与低质量位点，只作补充不作门控（`FREQUENCY_EVIDENCE.md` §7）；CMDB 已下线。本地病例库/本地人群频率库/羊水表达基线库若由用户提供，按与文献同等的证据规则计入（PM3 多次观察、PS4、BS1/BA1 本地频率、PP4），报告标注 `Local cohort evidence (unpublished)`；本地频率高于 gnomAD EAS 时优先用于 BS1。

## 6. 证据独立性、矛盾处理与重复计数审查

### 6.1 证据独立性原则（高勇）

Bayesian 假设各证据独立。若一证据是另一证据的重复或必然结果，不可叠加。

### 6.2 证据优先级（李茹 2026-09 正式版，由高到低）⟦培训班⟧

**人群频率（BA1 独立；BS1/PM2）> 功能验证（PS3/BS3、PVS1(RNA)/BP7(RNA)）> 家系（PS2/PM6/PP1/BS4）> 相位（PM3/BP2）> 保守/结构（PP2/PM1）> 计算预测（PP3/BP4，权重最低）**

> 2026-05 备课会版本为"人群 > 家系 > 功能"，2026-09 正式讲稿更新为功能验证优先于家系并新增"相位"档；本技能按正式版。注意：无 RNA/功能实验时，PVS1/PM4 与 PP3 同属"预测型"证据，与人群数据冲突时不享有高于人群数据的优先级。

最常见冲突：计算预测（PP3/BP4）vs 人群/流行病学（BA1/BS1/PM2）。

### 6.3 矛盾证据处理原则（李茹）

| 原则 | 说明 |
|------|------|
| 优先考虑独立性 | 用任何证据前检查来源是否与已有证据重叠 |
| 群体频率 > 计算预测 | 冲突时人群频率权重更高 |
| 功能检测与计算预测非叠加 | 需按基因/结构域实证 |
| 功能实验 > 计算预测（强度操作） | PS3 ≥ Strong 与 BP4 方向相反时，BP4 至多 Supporting 或不计（§3.3） |
| 采用 Bayesian 量化 | 定性矛盾转定量，避免主观 |
| 关注 VCEP 基因特异规则 | 不同基因有特殊组合规则 |
| ⟦培训班⟧ 良性方向不得"托底" | 其他证据均指向良性时，不得用 PP2/PM2 把变异托在 VUS（这是 6.4"PM2+BP4→VUS"的上位原则：后者仅指只有这两条证据的情形） |
| ⟦培训班⟧ PP5/BP6 已废止 | ClinGen SVI 2018 废止 PP5/BP6，不赋值；外部实验室分类只进模块 4/5 对标（GeneBe 等自动工具仍在用 PP5，对标时须剔除） |
| ⟦培训班⟧ 历史分类被推翻须标注 | 曾为 P/LP 而现被 BA1/BS3 等推翻的变异，报告写"历史分类已被推翻"；仅因规则版本变化（PM2 降级、REVEL 阈值更新）的边界重分类须标注"基于新分类规则"并提示易再变 |

### 6.4 冲突组合判定表（李茹）

| 冲突组合 | 判定 | 规则 |
|---------|------|------|
| BA1(AF>5%) + PP3/PS2 | 良性(B) | BA1 一票否决所有致病证据（白名单除外） |
| BS1 + PP3 | LB/VUS | BS1 权重 > PP3，频率越高越偏 LB |
| BS1 + PS2(de novo) | LP/VUS | PS2 仍有效；BS1 强则降 VUS |
| BS1 + PM6 | VUS | 冲突抵消 |
| PM2 + BP4 | VUS | 冲突抵消，需功能/家系验证 |
| PP3_Strong + PM2_Supporting | VUS（5 分） | 预测再高也只是预测，不得抬高 |
| PP3 与 BP4 | 不计分 | 预测不一致，互斥不用 |

### 6.5 证据合并决策表（⟦培训班⟧ 高勇 2026-09，据 CanVIG-UK/ACGS 规范与 Garrett 2020）

五分类：**允许** / **谨慎**（附条件）/ **限制**（同一命题的两条证据合并后 ≤8 分）/ **禁止** / **不适用**。

**致病侧**：

| 证据对 | 决策 | 条件/理由 |
|---|---|---|
| PVS1 + PM1 / PM4 / PP2 / PP3 | 禁止 | 同属机制预测 |
| PM4 + PP3 | 禁止 | PVS1/PM4 为致病机制预测，PP3 不可额外叠加 |

## 8. ⚠️ 关键产前提醒（贯穿全流程）

1. 产前"致病性分类"与"出生后预后"是两个独立问题，证据链不同（见主 SKILL Step 0.6-0.7、模块8'）
2. 产前表型有限、动态、非特异，PS2/PM3/PP4 使用受限——宁缺毋滥
3. 高频亚效单倍型可与 LOF 反式致病（TBX6 范式），单杂合 LOF 检出时主动核查
4. 产前 LOF 关键决策点可用引产前胎儿脐血 RNA 验证升级 PVS1（TET3 范式）
5. PS2/PM6 已用则不叠加 PP4（ACGS 2024）；产前 de novo 表型特异性分级见 4.1.5 决策表，非特异生长参数（如头围偏小）不可当"高度特异"升档
6. 多基因座候选时 PP4 按比例分摊 + 封顶 +5，不全压单基因
7. 中国人群频率数据缺口影响 PS4/频率阈值，结果解读需保守
8. PM1 产前宁缺毋滥（见 3.5）：须满足"功能已确立 + 域内无良性变异 + 热点数据（可用 gnomAD MCR OE 量化）"三门槛，强制查 gnomAD 域内变异与 VCEP 规则；默认不与 PS3/PVS1 共用（VCEP 允许除外）、与 PP3 合计 ≤ Strong；序列注释 ≠ 关键功能域
9. ⟦培训班⟧ 产前样本先过 MCC 定量（§4.11）、嵌合与 VAF 核查（§4.1.8/4.1.9）、同源区可比对性（§2.5b）三道前置门，再谈证据
10. ⟦培训班⟧ 良性侧仅有计算预测时产前不出 LB；至少两条证据才出 LB/LP/P（§0）；GUS 基因封顶 VUS（§0）
11. ⟦培训班⟧ "致病 ≠ 病因"：报告分"分级 / 归因（超声表型吻合度陈述）/ 再发风险"三段；找到致病变异后寻找不停止；BP2/BP5 产前默认不赋（§4.6）
12. ⟦培训班⟧ 再发风险不得套固定值：生殖细胞 de novo（亲代 VAF 0）→ 低但不为零（生殖腺嵌合不可用外周血排除）；胎儿合子后嵌合 → 更低；亲代杂合（VAF 40–60%）→ 50%（AD）/ 25%（AR）；亲代嵌合 → 区间，待多组织定量；印记基因按传递亲本性别；X 连锁按胎儿性别
13. ⟦培训班⟧ 遗传自"健康"亲代 ≠ 良性证据：亲代须完成基因特异靶向评估（§4.1.8）；"AD 遗传自亲代→再发 50%"与"遗传自亲代→倾向良性"两句话术在亲代嵌合时均不成立
